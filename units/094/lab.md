# DL094 实验：验证反向SDE与概率流ODE

## 目标和准备

本实验使用解析score，研究数值方法，不训练生成网络。数据全部为原创合成高斯样本。默认40000个粒子，两种方法、五种步数，纯CPU NumPy运算，无外部数据下载。运行Python 3.10或以上和NumPy、Matplotlib环境。

```bash
python experiment.py
python tests.py
```

输出包括outputs/data.npz、outputs/metrics.json和三张figures图。数据文件保留初值、所有步数的终点、200步前8条轨迹、精确ODE映射、正向方差序列。固定种子使协议可重跑，浮点末位可能随后端变化。

## 1 运行前手算

记录μ=0.7、v0=0.5、β=2、T=1。算出终点方差2.5、终点标准差√2.5。再写score(x,t)=−(x−0.7)/(0.5+2t)。t=0时均值右侧1单位的score为−2；t=1时为−0.4，说明高噪声时场更弱。

在纸上写出u=T−t，正步长h。SDE更新系数为β，ODE为β/2。随机增量是√(βh)乘标准高斯。检查每项量纲与符号，再打开reverse函数核对。

## 2 核对实现

reverse每步先使用tk=T−kh计算当前score，再进行显式更新。两种方法共享同一初始样本。SDE需要随机数生成器，ODE不使用随机增量。路径数组仅保存前8个粒子，不能把8条路径当作分布检验的全部样本。

discrete_variance不模拟粒子，而是精确递推数值方法的总体方差。它输出与样本方差不同的证据：前者隔离离散偏差，后者包含有限样本波动。请逐行对照主讲义两条递推，尤其注意平方作用在整个乘法系数上。

## 3 查看路径和边缘

图1横轴是递增反向经过时间u，不是正向时间t。ODE轨迹平滑并向μ收缩；SDE轨迹可能暂时远离μ。图2比较200步终点直方图与精确目标，不要求两种方法的逐样本输出相同。

记录200步时两种方法的sample_mean、sample_variance、ks_to_target。CDF距离按排序样本与解析正态CDF计算，同时检查阶梯函数左右极限。它是描述性距离，不是“分布一致已被证明”的证书。

## 4 分离两种误差

为每个方法和步数记录：

- 离散偏差：discrete_theory_variance减去0.5
- 抽样偏差：sample_variance减去discrete_theory_variance
- 总观察偏差：sample_variance减去0.5

检查前两项相加是否等于第三项。默认200步ODE数值总体方差约0.502004，样本方差约0.498870，说明抽样偏差可以使总偏差改变符号。

再看ode_200_rmse_to_exact_map。它比较同一初值下数值轨迹终点与精确ODE映射，是另一种不混淆初始分布抽样偏差的误差量。不要将其与SDE不同随机路径之间的逐点差比较。

## 5 故障注入

在复制的实验目录一次只改一个因素：

1. 把SDE漂移负号颠倒，预期方差增大，分布验收失败
2. 删除SDE噪声但保留完整βscore，预期收缩过强
3. 把随机项√(βh)改成√β乘h，预期网格加密时随机扩散错误消失
4. 把终端初值改为标准正态，保持正确score与求解器，检查步数增大不能修复初始失配
5. 将score乘0.9，检查更细步长只能收敛到被改动的动力学

每次改动前写预测，运行后说明是哪一个单元测试或分布诊断首先发现问题。不要改测试阈值来掩盖故障。

## 6 合理扩展

若研究强收敛，需要预生成细网格Brownian增量，并将相邻增量相加构成粗网格；对同一初值、同一路径耦合比较不同网格。当前不同步数使用不同随机种子，不能直接用逐点差估计强误差。

若研究采样误差，可固定步数200，把粒子数改为1000、10000、40000，使用预定多个种子。报告CDF距离和方差偏差的分布，不只报告一次最优结果。

## 验收与提交

本批5项测试通过。200步终点CDF距离要求小于0.02，均值误差小于0.03，各设置样本方差与其数值总体方差差异小于0.025。阈值针对固定规模教学协议，并非通用统计显著性标准。

提交三图、原始指标、测试日志和一页结论。结论必须说明时间方向、精确终端初始化、解析score、离散误差与抽样误差的区别，以及尚未验证一般非高斯或学习score模型。
