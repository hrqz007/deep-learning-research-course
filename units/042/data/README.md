# 原创合成重复测量数据

所有输入为独立编写的生成器产生，不含真实个人或设备资料。运行generate_data.py --destination 新目录可重建三个CSV，不会自动更改协议。

- 训练：40实体，224行，种子4200
- 验证：32实体，190行，种子4201
- 测试：160实体，788行，种子4202

每实体中心在[-2,2]²均匀采样，中心第一坐标为负时8次测量，否则2次。输入是中心加标准差0.05的二维独立高斯扰动。目标是0.7sin(1.5x1)+0.35x1x2+0.25x2²，加同一实体共享的标准差0.25高斯偏移，再加每行标准差0.08的独立高斯噪声。中心与偏移不作为特征公开给训练接口。

字段：row_id唯一行号；entity_id独立拆分、评价单位；replicate实体内重复编号；x1/x2唯一模型输入；y连续目标；region来自实体中心的左右区域。region不能从带噪x1重新定义。ID、重复编号、region都不送进MLP。

训练实体间独立，同一实体内测量相关。实体权重每行1/(G×实体重复数)，行权重1/N。全部预处理仅用训练实体拟合。测试数据只在选择冻结后解析评价；公开标签仅为复跑，不适合作为反复调参的盲测。

protocol.json在训练前固定候选、预算、基线和区间。fixture-hashes.json与脚本内嵌摘要用于核对三个CSV和协议。身份记忆反例另在experiment.py中由种子4280生成，完整80×4观测存在outputs/identity_leakage.json，不与主数据混合。
