# 原创合成数据

config.json 固定一个2×3实矩阵和四个2×2对角逆问题，均无量纲。matrix 是行输入 x(1,2) 到输出 y(1,3) 的映射权重；最后一列为零，方便核对矩形SVD。epsilons 是 diag(1,ε) 的第二个对角元；delta 是右端扰动 δb=(0,δ) 的第二坐标。它们均为正数。

默认δ=10⁻⁶，ε依次为1、10⁻²、10⁻⁴、10⁻⁶。所有输入是本讲原创教学数值，不来自用户、真实人群、业务、测量或预训练模型。没有训练验证测试拆分，因为本讲不拟合模型也不估计泛化。小奇异值信息反例另在代码中明确给定 diag(10,0.1) 与两行输入(1,1)、(1,-1)。

修改矩阵或ε会改变报告；正文手算对应本文件原值。不得把修改后的结果继续标成默认结论。
