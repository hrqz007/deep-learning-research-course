## 任务A 先算再看返回值

把W=[[3,1,0],[1,3,0]]写在纸上，逐项算WWᵀ，验证u₁=(1,1)ᵀ/√2、u₂=(1,−1)ᵀ/√2对应16和4两个特征值。再用vᵢ=Wᵀuᵢ/σᵢ求右奇异向量。写清为什么奇异值是4和2，不是16和4。

运行Notebook的“约简SVD”格。预期U.shape=(2,2)、s.shape=(2,)、Vt.shape=(2,3)。用UᵀU与VtVtᵀ核对正交性，用(U*s)@Vt核对重构。这里s是按列缩放U的一维数组；若不熟悉广播，先改成U@np.diag(s)@Vt。

检查点：允许uᵢ、vᵢ同时变号，不要求与纸上每个元素相同。记录最大绝对重构误差，并解释它为什么应很小却不一定精确为0。若你的程序通过全等号比较失败，不要立刻认定SVD错了。

## 任务B 截断与两种误差

对k=0、1、2调用rank_k。k=0得到全零矩阵；k=1应约为[[2,2,0],[2,2,0]]；k=2恢复原矩阵。每个结果仍是2×3，k不是输出数组列数，而是允许保留的方向数。

分别核验Frobenius误差√20、2、0以及谱误差4、2、0。前者测所有元素误差的平方和，后者测最坏单位输入的输出误差。最后一项在浮点计算中按接近0检查。填写rank_errors.csv时，observed值和尾部公式应在容差内相等。

```python
from experiment import rank_k, frobenius
import numpy as np
W = np.array([[3., 1., 0.], [1., 3., 0.]])
for k in range(3):
    print(k, frobenius(W - rank_k(W, k)))
```

检查点：80%保留平方能量不等于80%“准确率”，也不等于20%相对范数误差。自行计算2/√20，写出两种百分比的分母。再用输入x=(1,−1)/√2验证谱误差2可以真正达到。

## 任务C 证明任务信息可以与能量排序相反

固定H=diag(10,0.1)，输入两行(1,1)、(1,−1)，标签分别为+和−。先用完整H，再用rank_k(H,1)计算输出。观察第二列从±0.1变为0，而第一列都为10。

## 任务D 让一个小扰动走到弱方向

data/config.json的δ固定为10⁻⁶，ε取1、10⁻²、10⁻⁴、10⁻⁶。每次构造Wε=diag(1,ε)，解xWε=(1,0)，再解x′Wε=(1,δ)。应使用solve_row，它通过转置调用线性求解器，不能把行方程直接交给列方程接口。

逐行记录κ₂、相对右端变化、相对解变化、放大倍数和对新右端的残差。预期放大倍数为1、100、10000、1000000。ε=δ=10⁻⁶时，x′应为(1,1)。解释“输入扰动很小”指右端相对变化10⁻⁶，不是说参数解也只改了10⁻⁶。

追加对照：将δb改成(δ,0)，其余不变。观察同一病态矩阵的安全方向放大倍数为1。没有这个对照，很容易把条件数误解成每个扰动的固定放大系数。

## 任务E 检查残差不能代替解误差

仍令ε=10⁻⁶、原右端b=(1,0)。取候选解x̂=(1,1)。手算x̂Wε−b=(0,10⁻⁶)，残差范数10⁻⁶；真实解x=(1,0)，相对解误差为1。

再看脚本报告中的perturbed_residual，它相对于新右端b+δb计算，理论上应为0，浮点下应接近0。请在报告中区分原右端残差与新右端残差，不能把它们混写成同一列。这个任务说明小残差是必要诊断，但病态时不是解可靠性的充分证据。

## 任务F 把数值秩的阈值写出来

对diag(1,10⁻⁸)，分别调用numerical_rank(...,1e-10)与numerical_rank(...,1e-6)，结果应为2与1。再试阈值恰等于第二奇异值的对角例diag(1,0.5)，τ=0.5，结果为1，因为代码使用严格大于。

接着将diag(1,10⁻⁸)整体乘10⁶，再使用原绝对阈值。说明为什么数值秩判定会受到单位和阈值选择影响，而数学秩不会。可与np.linalg.matrix_rank默认结果比较，但记录NumPy版本；默认阈值不等于你真实测量的误差上限。

## 任务G 主动触发失败

不能只测试正确输入。请验证下列输入会被明确拒绝：一维数组、空矩阵、布尔、复数、文本、非有限数；k为负、超过min(shape)、非整数或布尔；阈值为负或非有限；矩形矩阵求逆问题条件数；右端shape不为(1,n)；奇异矩阵求唯一解；最终计算溢出。

```python
from experiment import rank_k
try:
    rank_k([[3., 1.], [1., 3.]], True)
except TypeError as error:
    print(type(error).__name__, str(error))
else:
    raise AssertionError("Boolean rank budget was silently accepted")
```

原始Python容器中的布尔值会在NumPy自动类型提升前拒绝；已被外部代码转成数值dtype的数组不保存来源，函数无法还原。函数只承诺非空二维有限float64输入，不承诺任意动态范围的稳定SVD。返回无穷条件数只用于算出的最小奇异值恰为0；极大有限比例超出float64范围时明确报错。
