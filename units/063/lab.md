## 一 用手算验证指标代码

### 任务A 质量与覆盖

构造100个点：40个在中心0，30个在中心1，20个在中心2，10个远离所有中心。半径仍为0.35，最低频率仍为1%。不运行代码先算有效比例、覆盖数、有效条件分布及熵。然后调用mode_metrics核对。解释熵使用90作为分母，而覆盖使用100作为分母的理由。

再构造200个点：只有1个在中心0，199个远离所有中心。质量应很低，覆盖应为0。若你的实现返回覆盖1，请查它是否误用了有效点数作覆盖分母，或把“出现过”当成“达到最低频率”。这里错误不会导致Python崩溃，因此必须用有明确答案的样例测试。

### 任务B 高斯距离

一维真实均值0、标准差1；生成均值1、标准差2。手算距离并说明为什么不是把方差1与4直接相减再平方。接着构造二维对角协方差Cr=diag(1,4)、Cg=diag(4,1)，均值差(1,0)，手算结果。

代码接收的是样本而非任意均值协方差，随机抽有限样本时结果不必等于理论值。若要验证解析矩阵公式，可单独调用psd_sqrt，或构造对称点集精确匹配指定样本矩。不要因为随机样本结果有0.01差距就立刻认定公式错了。

```python
import numpy as np
import experiment as e
x = e.centers().astype(float)
a = np.pi / 8
rotation = np.array([[np.cos(a), -np.sin(a)],
                     [np.sin(a),  np.cos(a)]])
y = x @ rotation.T
print(e.mode_metrics(y))
print(e.gaussian_feature_distance(x, y))
```

记录两个输出为何并不矛盾。把同一对样本都乘10，检验坐标距离是否乘100。再只缩放一组，解释为什么此时不能用同一个简单倍率关系。每一步都要写清缩放发生在原始样本、特征还是最终指标上。

## 二 重训两类模型并核对预算

### 任务C 跟踪一次VAE更新

阅读train函数中的VAE分支。标出训练批次x、重参数化噪声ε、编码均值μ、对数方差lv、解码均值pred、NLL与KL的形状。批量128时，x和pred为128×2，μ和lv也为128×2，NLL与KL各为128维，最终loss是标量。

写出本课固定观测标准差0.15的意义。生成代码为何在decoder(z)之后仍然加噪声？把means与samples分别画出可以帮助理解，但主表必须继续评价samples，不能看到means更集中就无声替换采样定义。

### 任务D 跟踪一次GAN更新

判别器更新时生成点被detach，防止更新生成器；生成器更新时冻结判别器参数，却保持判别器对输入的梯度。找到这两处代码并解释：若整个判别器前向放在no_grad内，为什么生成器会失去需要的学习信号？

核对protocol.json：三种子11、23、37，批量128，主模型更新4000，生成数4096。分别记录VAE和GAN的参数量、辅助网络参数量、优化器调用次数。两者各看4000个真实小批次，但GAN还有4000次判别器优化。因此“更新次数完全一样”“计算成本完全一样”都不是准确表述。

### 任务E 保留完整结果

把六行有效比例、覆盖和三种特征距离写到你的报告，不能只写最佳种子。计算每类质量均值与样本标准差，但保留原始三行，因为三个种子不足以精确估计尾部失败概率。检查距离排序是否随特征改变，并用讲义中的几何盲点给出一个可检验解释。

建议报告一句形式为：“在某数据、某预算、某指标下，观察到某差异；其他指标出现某结果；尚不能推出某结论。”这里的限制必须具体，例如尚未比较图像、尚未匹配FLOPs、尚未搜索最优超参数，而不是笼统地说“可能有局限”。
