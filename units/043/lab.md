## 3 纸笔账本：先不用框架

复制讲义的两幅3×3图、核和标签。在纸上画出每幅图的四个2×2窗口，按行优先记录输入。对每个窗口填写四个乘积、偏置、Z、ReLU开关和H，然后计算每例预测、残差、损失与两例均值。

接着逐条写局部导数：样本平均1/2、平方损失残差、空间平均1/4、ReLU门、核对应输入值。对同一个参数先加所有空间路径，再加所有样本路径。至少为k01和偏置写出未化简的四项和，不只抄最后数字。

最后统一更新全部5参数，再从原始输入开始重算。第一例的误差应当变大，而平均损失下降；解释它为什么不是梯度错误。加做第二轮时，重新计算残差和门，不能沿用上一轮上游。

可在脚本中调用hand_ledger读取Fraction精确分数。检验时比较精确值或充分位数的浮点近似；不要用正文四舍五入表格递推后宣称程序不一致。

## 4 从零实现的接口与shape检查

读conv_forward，但先自己写一版仅N=1、C=1、无填充的实现。通过手算后再加入批次、通道、步幅、补边与膨胀。每增加一个功能，就构造一个尺寸不对称的小例子，避免行列交换后恰巧shape仍正确。

函数输入x为NCHW，kernel为输出通道×输入通道×核高×核宽，bias为输出通道长度的一维数组。返回输出也是NCHW。conv_backward的upstream必须与输出shape完全相同，返回dx、dk、db。它不会自动决定损失均值或求和，因此你要在调用处放入正确上游。

```python
import numpy as np
from experiment import conv_forward, conv_backward
x = np.arange(12.).reshape(1, 1, 3, 4)
k = np.ones((2, 1, 2, 2)) / 4
b = np.zeros(2)
z = conv_forward(x, k, b, stride=(1, 2))
u = np.ones_like(z) / z.size
dx, dk, db = conv_backward(x, k, b, u, stride=(1, 2))
print(z.shape, dx.shape, dk.shape, db.shape)
```

这里目标是所有输出的平均值，不是MSE，因此上游是1/z.size。预期形状依次为(1,2,2,2)、(1,1,3,4)、(2,1,2,2)、(2,)。换成平方损失时要再乘残差；不能只因shape正确就认定梯度正确。

本API只支持groups=1、对称零补边、有限实数、正整数步幅/膨胀。大尺寸防护、错通道、NaN、复数或不支持的groups应清楚报错。资源上限见README，不用极端输入的崩溃替代日常有效域内的科学核验。

## 5 四种互补的梯度证据

第一种是PyTorch独立后端：以相同x、kernel、bias与upstream构建Conv2d，再对标量内积sum(z*u)反传；比较输出及全部输入/核/偏置梯度。测试覆盖多通道、非方形核、不等步幅、非零补边与膨胀。

第二种是中心差分：只对一个坐标加减小步长，其余全部不变，比较同一标量目标的变化。选平滑线性算子时没有ReLU拐点；若核验完整ReLU网络，要先保证扰动不改变门状态。步长太大有截断误差，太小有舍入误差。

第三种是伴随检查：独立构造线性矩阵A，检查dx是否等于A转置乘上游，以及两边内积是否一致。它可发现遗漏重叠路径或错误裁剪，但不能单独证明核参数梯度正确。

第四种是纸笔精确账本：只依靠Fraction逐窗乘加，核对三次参数状态、预测、所有5参数梯度与两幅图的输入梯度。避免只把同一个实现重复调用两次就称作两个参照。

test_experiment.py把这些检查组织成9个有含义的测试组，并在正常与-O模式都执行。数量不是质量目标，重点是每个检查能排除什么错误、还留下什么盲区。

## 6 平移实验：运行之前先填条件

针对下面七项，先写平移域、步幅、输入位移、输出位移或对齐方式、比较坐标和你预计的结果，再运行symmetry_audit。

1. 零填充、步幅1，全图对比右移1列前后
2. 同上，只取行1至6、列2至6的预定内部区域
3. 周期边界、步幅1，全图循环右移1列
4. 周期边界、步幅2，输入移2列、输出移1列
5. 周期边界、步幅2，输入移1列、输出不移的诊断
6. 同上，硬把输出移1列的诊断
7. 周期边界、步幅1，再加逐点ReLU

前两项必须同时报告，不能只展示内部0误差而隐藏边界。第5、6项没有正确整数输出平移作为理论对应，不要把它们的非零差写成“推翻卷积等变定理”。

再比较三种标量头：周期卷积+ReLU+全局平均、零边界版本、周期卷积+ReLU+固定位置权重。记录移前移后具体值，并用求和项是否仅被置换解释结果。

## 7 真实核辨识与优化参照

执行experiment.py会重新生成精确账本、平移探针和全部80次训练更新，而不是把旧results.json复制到新目录。核心训练由自写NumPy前反向完成；独立PyTorch模型同步走同一80步并逐步核对。

输出learning.trace保存第0至80步的参数、偏置与训练损失，共81个状态。test_prediction与test_target保留全部20图的完整结果。最小二乘使用独立窗口设计矩阵，直接给出本训练目标的线性优化参照。

至少回答：学习核与真核的差来自什么？学习核与最小二乘解的差又来自什么？如果训练时间翻倍但测试误差略有随机变化，能否直接说卷积改善了泛化？必须先区分优化差、采样差与评估选择。

参考量级：80步训练half-MSE约0.001804，测试约0.001840；最小二乘训练约0.001243。固定常数测试约0.077777。先检查损失的1/2和平均轴，再判断自己的结果是否“差一倍”。
