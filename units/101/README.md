# 101｜并行服务与系统级瓶颈

先读[讲义](lecture.md)，完成[实验手册](lab.md)，最后对照[答案](answers.md)。对应PDF同名，Notebook为experiment.ipynb。

## 复现

在本讲目录安装requirements.txt，然后运行python experiment.py与python tests.py。Notebook按序运行，会重新产生outputs与figures中的数据。无需外部数据、GPU、付费服务。环境版本见environment.json。

## 文件与证据

- experiment.py：完整可重放实验
- tests.py：数值与协议断言
- outputs：全部数据、结果与运行证据
- figures：机制图和实测图
- manifest.json：本讲文件清单与摘要

墙钟时间随CPU和负载变化，不要求逐位一致。实验限制、模拟指标和真正实测指标见讲义及结果字段。
