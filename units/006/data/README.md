# 六台虚构设备的原创合成数据

A至D各四行，x依次1、2、3、4。标签以2x+1为基础，加上刻意安排的扰动：A为0、0、1、0；B为-1、0、0、1；C为0、1、0、-1；D为1、-1、0、0。E验证标签为2x+1；F教学测试标签为2x+3。全部为课程原创构造，不对应真实测量。

id由设备字母和位置组成。device是拆分单位，x是预测时已有的旋钮位置，y是之后读取的屏幕值。训练设备A/B/C/D、验证E、测试F预先固定。本例演示新设备留出，不对未来时点或其他设备人群作统计保证。

测试标签单列文件用于演示冻结流程；所有答案公开，不构成未知盲测。数据文件摘要在运行时记录，不在此人工抄写可能过时的版本值。
