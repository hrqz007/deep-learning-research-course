# 教学数据与固定配置

所有样本为本课程原创的无量纲合成量，无现实个人资料。第i行i=0,…,71：x1=((13i mod23)−11)/5，x2=((7i mod19)−9)/4，y=0.7x1−0.4x2+0.2x1x2+0.05((i mod5)−2)。最后一项是确定的周期扰动，不宣称独立同分布随机噪声。

samples.csv保留id、x1、x2、y。文件中的十进制数由Python二进制浮点计算后以17位有效数字保存；实验以这些固定字节为准。split.json明确列出45/15/12三个互斥集合，其并集是全部72个ID。生成时使用Python random.Random(300)打乱ID再分块，读取时不重新抽拆分。

config.json固定12轮、第4轮检查点、batch size7、隐藏宽度4、Dropout0.25、SGD学习率0.04和动量0.8、初始化种子300、加载种子301、float64、单进程加载与保留末批。标准化均值和总体式尺度仅从训练45行计算，并作为模型buffer保存。

experiment.py内置这三份原始文件的SHA256，固定报告入口先核字节。make_figures.py与Notebook首单元还核对8份提供的输出，防止更换输入后继续使用旧图。哈希只能检验字节身份，不证明数据设计科学合理。
