## 3 逐行拆开核心计算

```python
import numpy as np  # np是数组工具的简称，不是新的数学对象。
from experiment import logistic  # 使用稳定实现，返回损失和梯度。
from generate_data import generate  # 原创数据可重新产生。
d = generate()  # d是字段名到数组的字典。
w = np.zeros(2)  # 两个参数先设为0；零向量没有方向。
loss, grad = logistic(w, d['x'], d['y'])  # 先算当前平均损失和坡度。
w_next = w - 0.1 * grad  # 用0.1步长走一次；不是完整默认实验。
print(loss, grad, w_next)  # 输出应与下列手算核对。
```

起点损失应为log(2)≈0.693147。因为sigmoid(0)=1/2，梯度为负二分之一乘yx的平均。本数据yx平均为(1.1,1.2)，所以梯度为(-0.55,-0.6)，小步后的w为(0.055,0.06)。如果你的结果差一个10倍，检查是否漏除了样本数；如果符号相反，检查标签是否用了0/1。

打开experiment.py，按顺序追踪logistic、descent_quadratic、train_logistic和run。np.logaddexp计算稳定log损失；x.T把样本维移到乘法内侧；copy确保历史参数不会全部变成同一帧。对每行写一句“输入形状→运算→输出形状”。

## 4 用保存数组独立复核

```python
import numpy as np  # 读取数值数组，不使用pickle。
a = np.load('my_run/trajectories.npz', allow_pickle=False)  # 只加载自己的文件。
t = np.arange(1, 51)  # 界从第一次更新开始，排除除以0。
excess = a['quad_loss'][1:] - 40 / t  # 正值才表示越过上界。
print(excess.max())  # 固定实验应约为-0.8。
m = a['run0_metrics']  # 每列含义见data/README.md。
print(m[10], m[-1])  # 比较相同轨迹的第10步和最终状态。
w = a['run0_weights'][-1]  # 取真正保存的最后参数。
print(np.min(a['y'] * (a['x'] @ w)) / np.linalg.norm(w))  # 独立重算几何间隔。
```

输出允许最后几位浮点差异。第一次零参数的角度是NaN，因为方向未定义；不要把它填成0度，否则会伪造“一开始就对齐”的结论。把JSON的最终角度、损失与上述数组重算结果放入自己的报告。
