# 第015单元合成参数

config.json由本课程原创构造，不含真实个人、真实训练样本或外部数据。

- hessian：常数对称正定矩阵[[13,-12],[-12,13]]，曲率1和25
- initial_point：严格行形状(1,2)，默认[[2,0]]
- step_sizes：相互独立运行的固定步长，不是一个随时间变化的日程
- iterations：更新次数，输出包含初始状态，默认60次更新产生61行
- taylor_steps：F=x⁴+y²/2在(1,1)沿(h,2h)的正增量
- seed：保留的元数据；当前实验没有随机数调用，不依赖这个值
- 所有坐标、目标值和步长均为无量纲教学数

改变H后脚本仍要求正定；不对称、半正定和不定矩阵可在核心单独函数中用于边界讨论，但不应套用正定稳定范围。新增配置请另存并选新输出目录。结果只说明对应合成函数的行为。
