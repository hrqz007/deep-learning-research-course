# 代数函数与图像语言练习详解

## 第007单元 把条件写进每一步答案

以下对应讲义的九题。每题既给数值，也交代对象、允许输入与运算顺序。若你得到相同数字但用了除以0、错误单位或未定义的对数，这仍不是合法解答。所有例子是课程合成教学例子。

## 第一题 三种方程情况

对2x+1=7，两边减1得到2x=6。因为2不为0，可以两边同除以2，得到x=3。代入核验2×3+1=7，所以3是解；这些步骤可反向恢复原式，没有引入或丢掉其他解，因此是唯一解。

对0x+3=3，任何实数x都使左侧等于3。解是全部实数，不是仅仅x=0。若另给设备定义域，答案应改成该定义域里的每个输入。

对0x+3=4，左侧恒为3，无论怎样选x都不会变成4，因此无解。两题都不能先写x=(c-b)/a再代入a=0。

一般地，ax+b=c在a≠0时可逐步变为ax=c-b、x=(c-b)/a。当a=0时，只检查b=c是否成立。程序用unique、all_real、no_solution三种状态表达数学区别，不能让一个数0兼任三种含义。

## 第二题 定义域和值域

已知任务把输入限定为0≤x≤5，因此定义域是[0,5]。方括号表示包含左右端点。f(x)=2x+1随x增加而增加，端点分别给f(0)=1、f(5)=11，因此值域为[1,11]。

还可以直接检验中间的输出有没有遗漏：任取满足1≤y≤11的y，反解x=(y-1)/2，必有0≤x≤5，所以这个区间内的每个y都能由允许输入得到。仅算两端，在没有单调性或其他论证时，并不总足以确定值域；这里直线关系使论证成立。

代数表达式可以给出2×100+1=201，但100不在这个任务的定义域中。它不证明设备支持100格，更不能证明未验证区域的真实装置会输出201。需要区分表达式的可计算范围、任务许可范围与经验验证范围。

## 第三题 厘米和毫米的等价系数

令x为同一长度的厘米数值，u为毫米数值，则u=10x、x=u/10。将原式的x整体替换：

$$y=2x+1=2\frac{u}{10}+1=0.2u+1.$$

原系数2的单位为读数单位/厘米，新系数0.2的单位为读数单位/毫米。偏置1仍为读数单位。只改变输入单位时不应随意改变它。

对3厘米即30毫米，旧表示得到2×3+1=7，新表示得到0.2×30+1=7。若把30直接代进旧系数，得到61；61不是换单位后的同一预测，而是错误模型的输出。

更一般地，若新输入u=kx且k>0，原式y=ax+b可写成y=(a/k)u+b。这个推导使用的是纯倍数换算；若单位换算还包含平移，例如某些温标之间的换算，必须把完整替换式代入，不能直接沿用这个特例。

## 第四题 指数表与负号

2的-2、-1、0、1、2、3次幂依次为1/4、1/2、1、2、4、8。负指数表示倒数，例如2⁻²=1/(2²)=1/4，不是给结果加负号。非零底数的零次幂为1；本题没有把该规则扩展到0⁰。

在(-2)²里，括号指定底数是-2，因此(-2)×(-2)=4。在-2²里，通常的优先级先计算2²再取负，结果-4。Python分别写(-2) ** 2与-2 ** 2，结果也分别是4、-4。Python中的^执行整数按位异或，不是数学的乘方符号。

```python
powers = [2 ** n for n in [-2, -1, 0, 1, 2, 3]]
assert powers == [0.25, 0.5, 1, 2, 4, 8]
assert (-2) ** 2 == 4
assert -2 ** 2 == -4
print(powers)
```

底数为负且指数不是整数时，实数结果需要额外条件，不能把本题整数幂规则不加区分地推广。本课程的一般实指数函数限定正底数。

## 第五题 对数的输入和底数

由于2⁻²=1/4，log₂(1/4)=-2。由于2⁰=1，log₂1=0。由于2³=8，log₂8=3。对数的结果就是对应的指数，不是“对输入再除以底数”。

一般$\log_a x$要求x>0、a>0、a≠1，讨论范围是实数。正底数的实指数值始终为正，所以0或负数不能当作这样的指数输出。a=1时所有指数都给出1，无法唯一反推出指数，因此不构成这种对数函数。

当0<x<1且a>1时，对数为负；输入依然是正数。底数在0与1之间也合法，只是对数随输入增大而减小。例如(1/2)⁻³=8，所以$\log_{1/2}8$=-3。自然对数ln的底数是e，math.log(x)默认采用这个底数；要算本题的底数2，应使用math.log2(x)或明确换底。

## 第六题 乘积公式的推导与反例

先设u=$\log_a x$、v=$\log_a y$，其中x>0、y>0、a>0且a≠1。按定义，x=aᵘ、y=aᵛ，因此xy=aᵘaᵛ=a的u+v次幂。把最后的关系反读，得到$\log_a(xy)$=u+v，也就是：

$$\log_a(xy)=\log_a x+\log_a y.$$

x=4、y=8、a=2时，左边log₂32=5，右边2+3=5。每一步的输入都为正，条件满足。这个数值核验帮助发现算错，但乘积恒等式的理由来自前面的指数规律。

“和的对数等于对数的和”不成立。取两个正数4与4，左边log₂(4+4)=log₂8=3，右边log₂4+log₂4=2+2=4。一组合法反例已经足以否定普遍等式。若两边在某一组特殊数字上碰巧相等，也不能由此恢复普遍结论。

延伸核对幂律：令x=aᵘ，则xʳ=a的ur次幂，所以$\log_a(x^r)$=r$\log_a x$，仍要求x>0。将x=aᵘ两边取ln，有ln x=u ln a，再利用ln a≠0，就得到换底公式u=ln x/ln a。注意这里的条件不因“整理公式”而消失。

## 第七题 三种目标与两种平均

约定每个数字都是正损失，数值越小越好，而且A与B都恰有两条记录。原算术平均A=(1+9)/2=5，B=(4+4)/2=4，因此原目标选B。

对这两个已算好的正平均值取log₂，A得到log₂5≈2.321928，B得到log₂4=2。由于底数2的对数递增，5>4变成log₂5>log₂4，仍选B。这里变换的是整个原目标。

若每项先取对数，再求平均，A得到(0+log₂9)/2≈1.584963，B得到(2+2)/2=2，因此这次选A。顺序变化发生在汇总内部，所比较的对象已变了。

| 目标 | A | B | 选择 |
| --- | --- | --- | --- |
| 原算术平均 | 5 | 4 | B |
| 原算术平均后取log₂ | 2.321928 | 2 | B |
| 每项log₂后平均 | 1.584963 | 2 | A |

这不是浮点误差造成的边缘结果。借助乘积公式，A的第三种目标恰为log₂3，B恰为log₂4，所以在精确数学中已有log₂3<log₂4。具体地，两个正数p、q满足：

$$\frac{\log_2 p+\log_2 q}{2}=\log_2\sqrt{pq}.$$

因此第三种目标等价于比较正几何平均。A的几何平均是√9=3，B的几何平均是√16=4，而算术平均分别是5与4。这正说明两种汇总可能把不同方案放在第一位，不说明哪一种对所有任务都最好。

若用底数小于1的对数而仍坚持最小化，整体变换也会反转大小方向，所以“单调”要进一步区分递增与递减。若数据含0，前面的正损失对数目标就不满足定义域；随意加一个小数或删行都在改变目标，需要另行说明。

## 第八题 复合顺序与复合定义域

f(g(2))先计算括号最内层的g(2)=2²=4，再计算f(4)=2×4+1=9。g(f(2))先计算f(2)=5，再计算g(5)=25。相同的两个函数，仅改变先后顺序就得到不同结果。

一般地，f(g(x))=2x²+1，而g(f(x))=(2x+1)²=4x²+4x+1。它们在某些特殊输入上可以碰巧相等，比如x=0；这并不说明两个函数处处相同。判断函数恒等，需要对全部允许输入成立，不能只选一个方便的点。

对log₂(x-1)，外层的输入是整个x-1，所以条件是x-1>0。两边加1得到x>1，定义域为开区间(1,∞)，端点1不包含。x=1时内层为0；x=0.5时内层为-0.5，都不允许取实数对数。x=2时内层为1，输出log₂1=0，给出一个合法核验点。

## 第九题 求和展开与分段边界

令a₁=2、a₂=4、a₃=6。三项求和的编号i逐个取1、2、3，因此：

$$\sum_{i=1}^{3}(a_i+1)=(2+1)+(4+1)+(6+1)=15.$$

每一项都加了1，共三次；另一种运算是原和加一次1，结果(2+4+6)+1=13。一般有n个元素时，逐项加1再求和等于原和加n，而不是加1。

rectifier的规则为x<0时输出0，x≥0时输出x。负数-2应输出0，边界0应输出0，正数3应输出3。下面三个测试分别针对负分支、边界和正分支；只测正数不能检验条件写反或边界遗漏。

```python
from experiment import rectifier
assert rectifier(-2) == 0
assert rectifier(0) == 0
assert rectifier(3) == 3
values = [2, 4, 6]
assert sum(x + 1 for x in values) == 15
assert sum(values) + 1 == 13
print("negative, boundary, positive and summation checks passed")
```

本例两个表达式在边界都给0，但分段覆盖仍须明确。若你把两个分支都写成严格不等号，可能在0没有返回值；若重叠分支给出不同结果，就必须消除规则歧义。尖角、没有定义、函数值跳跃是不同概念，本题只要求先正确确定函数值。
