# 033 合成教学数据

没有真实个人数据或外部数据下载。

- hand-example.json：X=[[1,2],[-1,1]]，y=[[0.7],[-0.2]]。9参数按W行优先4项、隐藏偏置2项、输出权重2项、输出偏置1项排列。两次学习率0.1、0.05，动量0.8，两次都使用同一数据。
- samples.csv：8×6网格共48点。x1=-1.4+0.4i，i=0..7；x2=-1+0.4j，j=0..5；ID=6i+j。标签由0.5 max(x1+0.6x2,0)−0.3 max(−0.3x1+x2,0)+0.1生成。输入保留1位小数，标签保留6位；文件中的这些数值是运行时的确定输入。
- config.json：固定种子33，12epoch，每微批次4点、累积2次后更新；每epoch6更新，总72更新、576样本呈现。模型初值与手算相同，数据不同；四方案均使用同一组网格与相同排列。
- figure-input-sha256.json：3个输入和8个参考结果的摘要，供固定绘图和Notebook入口检查。不是外部文件真实性认证。

这里没有独立验证或测试划分。实验只比较当前训练集上的优化轨迹，不用训练loss估计泛化。NumPy不生成训练随机性；采样排列唯一随机源是独立的PyTorch Generator。
