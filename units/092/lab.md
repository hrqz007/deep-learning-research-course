# DL092 实验手册 多模态证据审计

## 1 你要交付什么

目标是在一个已知生成机制的任务中，区分单模态捷径、融合表达能力和训练干预。交付一份结果表、至少五个逐例审计、一段有范围限制的结论，以及一个你主动发现的替代解释。不要只提交命令运行成功的截图。

进入本单元目录。推荐Python 3.12，安装requirements.txt中的依赖；实验只使用CPU和本地合成数据，没有账号、外部数据集或收费API。PDF重建依赖系统Pango与中文字体，阅读现成PDF不需要安装它们。源码、数据生成机制与许可见DATA_LICENSE.md。

```bash
python -m pip install -r requirements.txt
python -m unittest -v test_experiment.py
OPENBLAS_NUM_THREADS=1 python experiment.py --output my_run
python make_figures.py
```

Windows PowerShell可以先设置$env:OPENBLAS_NUM_THREADS="1"，再运行python命令。make_figures.py读取随包固定outputs，避免把学习者的新实验悄悄混入教材。要绘制自己的结果，先在独立副本中修改脚本读入位置，并在图标题标注你的设置。

## 2 跑之前写下预测

不读结果，先为五种方法排列你预期的原域和提示反转域表现。特别写下concat与interaction的差异是否来自“看见更多数据”。两者看见相同v、b、z，但interaction多了确定性计算vb；这不是新观测，而是不同函数表达能力。

写下随机化训练可能失败的条件。例如视觉噪声太高时，压低提示依赖可能伤害原域；若现实提示本来就是权威事实，随机化它还可能改变合法任务。提出这些失败条件是研究协议的一部分，不是结果不好以后才补的理由。

## 3 验收数据与训练

打开outputs/data.npz，核对训练1200、验证400、测试800条，输入形状均为N×3。检查所有标签属于0或1，所有文本查询b属于-1或+1，且潜变量a没有进入features函数。

逐行解释features函数的五种返回值。交互模型有5个权重；其中最后一项对应常数偏置，第四项对应vb。fit函数每步重新生成独立提示，仅randomized_interaction执行这一步。其他方法与数据没有被偷偷修改。

运行完整实验后，results.json应包含120条逐种子逐域记录：5方法×3种子×8域。metrics.csv有相同数量的数据行。predictions.npz保存每一组合的800个概率，weights.npz保存15个权重向量。记录你本机时间，不要求与随包秒数一致。

## 4 手算任务

题1：列出a、b的四种组合及y。只给a时，为什么最佳总体准确率为50%？这一判断在文本中加入z后是否仍适用？

题2：对特征行F=[1.2,-1,-1,-1.2,1]，权重w=[0,0,0,1,0]计算分数与概率。若标签为0，交互权重的单样本梯度符号是什么？说明一次梯度下降会让什么变化。

题3：一个十题配对比较中，共同正确6题、共同错误1题、A独对2题、B独对1题。计算两模型错误率与A-B差值。为什么不能把共同错误丢出总体准确率分母？

题4：原样本a=+1、b=+1、y=1，替换文本后b=-1。如果仍用y=1评价，得到的是什么指标？如果要评价新问题，应如何重标？

## 5 逐例证据检查

选择shortcut_flip域里两个交互模型预测不同的五个样本。记录v、b、原z、翻转z、真实标签、两个概率及噪声组。检查误差是否主要集中在视觉信号接近0或被噪声翻转的例子。

不要只挑随机化获胜的样本。若存在原模型获胜的例子，也至少检查一个；若不存在，应明确在所检查集合未发现，而不是把这种情况推广成所有数据。逐例检查用于理解失效模式，不能替代全量指标。

以一个样本为例，比较question_counterfactual前后概率。理想任务行为需要标签翻转，但模型概率不必精确满足p_new=1-p_old，因为模型还存在偏置、噪声和残余提示依赖。把“方向正确”与“严格对称”等价起来会制造不必要的假失败。

## 6 主动植入三个故障

故障A：把features里的vb改成ab，但不要把修正提交到正式包。由于原函数拿不到a，这会迫使你显式加入潜变量。解释为什么这属于标签泄漏，哪一项数据字段审计会发现。

故障B：将permuted_relabelled的标签错误保留为y。运行单元测试应失败。修复后，说明配对置乱为何不是天然标签保持变换。

故障C：先对全体数据计算标准化参数，再拆训练测试。当前实验没有这一标准化步骤；请仅在独立副本中构造它，并说明这会泄露什么信息。即使没有用测试标签，测试分布统计也进入训练流程；是否允许取决于预定是否为传导式设置，不能默认无害。

## 7 一次新的小研究

只改变一个因素：将高噪声组标准差从0.9改成1.5。先固定你的假设、主要指标、种子和训练预算，再另存数据及结果。不要沿用旧文件名覆盖随包固定证据。

建议问题：当视觉测量变差时，提示随机化对提示反转域和原域的取舍是否更明显？报告两域和两组，而不是只保留支持预测的行。这是新的实验，不是原报告的重复验证；即使得到相反趋势，也应保留。

可选进阶：增加一个小MLP作为拼接基线，并用参数量、步数、样本量和真实时间报告预算。若它可以表达相等关系，concat逻辑回归的劣势就不能概括为“拼接永远无效”。这是对模型家族限制的检验。

## 8 研究报告模板

用600至1000字写清问题、已知生成机制、比较方法、固定协议、主要结果、至少一个不利结果、替代解释、许可与下一步。主结果必须来自你实际保存的JSON；如果没有重跑，明确是分析随包结果。

必须包含一句“当前证据没有证明什么”。合理例子是“没有证明自然图片与自由文本上的普遍鲁棒性”；不合理例子是用很小的边界声明之后又在标题声称通用可靠理解。

最后核对：每张图能追溯到数据文件；每个数字注明域与分母；所有置乱指标注明标签规则；没有用测试结果选择最好种子；没有将缺模态输入当作重训单模态基线；没有把合成噪声组称为真实人口公平性。
