## 3 相同训练预测与不同未来预测

推导Xz=0的全部非零方向。用w*=(0,1,1)和t=-1、0、1构造全部插值解的一部分，分别计算训练预测、参数平方范数、新点(1,1,0)预测。接着运行80步GD，确认零空间分量保持。

再令w=diag(1,1,2)u，比较最小u范数解与最小w范数解。写出两个算法是否优化同样的训练平方损失、是否有同样的函数类、是否选择同样的解。这三问应分别回答。

可直接运行以下完整片段；其中np.linalg.lstsq是独立参考求解入口，不调用主脚本的SVD解。

```python
import numpy as np
X = np.array([[1., 0., 1.], [0., 1., 1.]])
y = np.array([1., 2.])
w = np.linalg.lstsq(X, y, rcond=1e-12)[0]
S = np.diag([1., 1., 2.])
u = np.linalg.lstsq(X @ S, y, rcond=1e-12)[0]
print("ordinary", w, "rescaled", S @ u)
print("training predictions", X @ w, X @ S @ u)
print("new-point predictions", np.array([1., 1., 0.]) @ w,
      np.array([1., 1., 0.]) @ S @ u)
```

## 5 阅读全部容量曲线

在capacity.csv中筛ridge=0，对每个sigma、p保留12个seed。记录中位数、均值、范围和每次曲线。重点检查p=3、22、23、24、25、26、32、48、96，不能跨过插值附近密集点只画稀疏宽度。

## 6 核对风险而不是只看图

把拟合系数补零到96维，自己算与真β的平方距离。另将它拆为已建模参数误差和遗漏信号。核对它等于clean_risk，并说明为什么noisy_risk多出σ²。

再核对signal_error、realized_noise_norm2、cross_term的和。对于Ridge或p<3，查看cross_term是否非零；不要把对噪声求期望后为零的量直接从单次样本中删除。conditional_noise_mean_risk固定完整训练设计，仅平均新训练噪声；clean_risk固定这次训练标签，只平均新输入。

conditional-risk.json另外包含一个固定设计的400次噪声重复和一个固定拟合的4096新输入检查。标准误衡量Monte Carlo平均的波动，不是模型效果的置信保证，更不是12个主seed的标准误。

## 7 谱滤波与不符合直觉的结果

谱诊断使用X=diag(2,0.2)、y=(1,1)、η=0.4，检查0、1、2、10、100、1000步。按正文等比数列式手算两个坐标，再对照spectral-filters.json。解释小奇异值方向为何学得慢，完全拟合后为何需要大系数。

比较Ridge谱因子时必须保留nλ，不能把目标为平均损失的实现与总和损失公式混用。尝试反解使某一个方向的GD因子等于Ridge因子的λ，再检查另一个方向是否也匹配。
