# 固定Gaussian教学数据

全部是原创合成数据，不含真实个人、机构或私有记录。gaussian-fixture.json包含12次独立生成的数据设计，seed为3800至3811。每次numpy.random.default_rng(seed)先生成normal(size=(24,96))，再生成normal(size=24)。前者为输入X，后者为标准正态训练噪声epsilon。

真实beta在96维中前3项为1、-1、0.5，其余0；没有截距。标签不是外部下载数据，在每种sigma下按X @ beta + sigma * epsilon构造。每个p只取前p列，但标签保持来自完整真函数。p=1或2会遗漏真信号。

主实验固定18个宽度、3个噪声强度、3个Ridge系数，总1944拟合；同一seed内所有因素成对。12个seed改变设计和标签噪声，不改变算法初始化。CSV中的风险是已知生成分布的精确新输入期望，没有训练/验证/测试挑选过程。另一个固定seed3899只用于条件噪声平均和4096新输入的Monte Carlo诊断，不参加选型。
