## 二 任务A：前向公式与时间索引

从schedule()打印数组长度与前后几个数。应看到T=200、数组长度201，β0=0、α0=1、barα0=1，tildeβ1=0。β1至βT必须都在0和1之间，barα从1严格下降。写出训练randint的两个边界，并说明右边界为何要写T+1。

纸笔计算β1=0.1、β2=0.2时的α1、α2、barα2。给定一维x0=2，求x2条件均值与方差，再令整体ε=−1，求一次闭式样本值。之后用q_sample验证。务必区分“累计整体噪声ε”和“每一步单独噪声εt”。

```python
import torch
from experiment import schedule, q_sample
s = schedule(2, 0.1, 0.2)
x0 = torch.full((1, 2), 2.0)
xt = q_sample(x0, torch.tensor([2]), -torch.ones_like(x0), s)
print(s['abar'], xt)
```

统计任务：固定x0，分别用独立逐步噪声与直接闭式噪声抽50000个样本，比较各坐标均值和方差。两种方法应在抽样误差内一致，不要求同一编号样本相同。若每一步复用同一个ε，会出现什么额外交叉项？用两步展开式说明。

边界任务：确认t=0的q_sample精确返回输入；确认反向均值拒绝t=0；测试t=201、非整数时间张量和不匹配形状会抛出ValueError。普通与-O运行都应保留这些检查。若只使用Python assert做输入验证，优化模式可能移除它，不能当成稳健接口。

日程任务：将T保持200，把β末值改为0.02，比较barαT。不要重新训练，只比较日程和原始数据残余信号尺度。写出“200步不自动等于纯噪声”的理由，再说明换数据单位为什么也可能使先验近似变差。

## 三 任务B、C：后验、KL与训练目标

任务B从$q(y\mid x_t,x_0)\propto q(x_t\mid y)q(y\mid x_0)$出发，把y的二次项和一次项写清楚。求精度A与线性系数h，再读出方差1/A和均值h/A。以β1=0.1、β2=0.2、x0=2、x2=1核对数值。说明为何给定x0的后验可解析，并不意味着未给定x0的真实反向分布也是单个高斯。

用posterior_mean与reverse_mean做独立代码核对：先抽x0和整体ε，通过q_sample构造xt，再分别将x0与ε代入两种后验均值公式。对t≥2，两者应在float32误差范围内相等。这个核对使用的是已知训练噪声，不能直接拿它替代采样时的网络预测。

任务C写出同方差高斯KL，再代入噪声参数化，得到时间权重wt。请明确本代码损失是按两个坐标平均，而理论范数平方是坐标求和；两者差因子2。随后解释去掉wt为什么不是简单把所有损失乘同一个常数。

变分任务：从log pθ(x0)的潜变量积分写到Jensen下界，说明负号后不等式方向。把负ELBO拆成LT、中间KL、L0三类。指出固定日程下哪部分与网络参数无关；指出为什么t=1的tildeβ等于0，却不意味着应计算普通高斯KL中的log0。

端点任务：本课理论连续密度使用β1作为正的解码方差，默认展示采样却最后返回均值。解释两者差别，并找出terminal_noise开关。不能因为默认最后一步不加噪，就声称它是上述正方差端点分布的精确抽样。

提交时保留推导过程和一次数值核对。只抄wt公式不够：你应能说明它由哪两个系数平方得到、σt²是否固定，以及本实验为什么没有报告精确似然。
