# DL074 数据字典

原创离散概率总体，无真实业务字段或外部数据下载。

| 文件/字段 | 形状或值域 | 含义 |
|---|---|---|
| population.npz: x | [21] | [-1,1]等距输入，等概率抽取 |
| prob | [21] | 每个输入的P(Y=1)，0.15或0.85 |
| thresholds | [23] | 抽样前固定的命名阈值候选，含重复函数 |
| predictions | [23,21],0/1 | 候选在格点上的预测表 |
| sample.csv | 100行 | grid_index(0..20)、x、y(0/1) |

outputs/trials.npz保存上述总体、true_risks[23]与n20/n100/n500/n2000各[400,6]数组。六列依次是所有候选最大绝对风险偏差、ERM训练风险、ERM精确总体风险、记忆表训练风险、记忆表精确总体风险、选中候选索引(0..22)。风险为比例不是百分数。原始逐样本可由seed=740000+n*1000+repeat重新生成；重复编号0..399。data/sample.csv固定seed7400，仅为人可读演示样本，不是所有重复的拼接。
