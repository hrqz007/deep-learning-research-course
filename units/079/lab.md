## 5 分开测两个误差

预测MSE比较预测力与合成真值。等变误差不需要标签，计算predict(Rx)−Rpredict(x)。两者应分别报告，单位分别N²和N。本课对61个角度、256个位置取最大绝对坐标差。

题8。构造一个始终等变但预测很差的函数。再说明为什么61个角度通过，并不能单独证明任意角度都通过。结构证明与数值测试分别提供什么？

```python
import numpy as np
from experiment import rotation, predict, init, data
x, _ = data(sector=False)
p = init('equivariant', seed=12)
r = rotation(0.731)
left = predict(x @ r.T, p, 'equivariant')
right = predict(x, p, 'equivariant') @ r.T
print(np.max(np.abs(left - right)))
```

这段使用未训练权重，预期仍在舍入误差量级。若误差很大，先查按行/按列约定、转置、输出类型，再怀疑数值精度。不要通过把容差扩大到1来“修复”一个结构错误。
