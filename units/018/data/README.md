# 合成抽样机制

config.json定义4个等概率原子编号，其值为0、0、2、6。相同值0对应两个不同原子，所以P(X=0)=1/2，另外两值各1/4。每次随机选择一个原子编号，独立性是模拟器的生成假设。数值称为“损失单位”，不来自真实模型或个人数据。

sample_sizes表示一批记录的行数n。iid模式每行独立抽取；copied_groups模式先独立抽取G=n/copies个组，再把每个值完全复制copies次。组与组独立，同组完全相同。两个模式的单行边缘分布相同，但均值抽样方差不同。外层4000个重复是重新生成整批数据，不能与一批内的样本量n混为一谈。

group_observations.csv是独立设计的8组手算练习，用于Notebook读取核对；它不是模拟器4000次中的随机抽中样本。experiment.fixed_results内同一序列用于脚本输出，测试要求两者一致。组ID应保留，复制后的64行不能改称64组。

固定seed用于复现，不证明总体模型真实、不创造新的真实独立证据。伪随机生成器与高层抽样算法可能随Python版本改变；环境输出记录本次版本。
