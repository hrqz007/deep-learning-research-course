# 037 合成数据说明

全部为原创人工数据。唯一生成器为NumPy default_rng(3700)，按train48、validation96、test384的顺序分别调用uniform(-1,1,(n,2))，随后调用random(n)<.15得到标签翻转位。clean_y为(x1>0)，y为clean_y与flipped的异或。全局ID从0到527，每份CSV互斥。

x1是信号方向；x2是独立干扰方向。均匀输入在两方向镜像下均保持边缘分布，但若标签保持不变，只有x2镜像保留当前条件标签机制。文件中的clean_y不参与拟合或模型选择。

train.csv含48行，其中9条标签翻转，21条观测正类；validation.csv含96行，其中12条翻转，40条正类；test.csv含384行，其中59条翻转，191条正类。翻转率是一次有限抽样的结果，不强制每份刚好15%。

experiment.py内的DATA_HASHES冻结三个CSV的原始字节。交付CSV是读取的权威输入，默认运行不自动重新生成。以下描述可用于另建实验，但重生成之后应建立新的数据版本，不要改摘要来伪装成原结果。所有增强仅作用训练中的输入副本，不覆盖原CSV。
