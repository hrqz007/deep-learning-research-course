## 结果与边界

七个处理各三种子，共21次。非早停各160轮480步；早停分别37/24/25轮停止并恢复17/4/5轮。合计8898次更新、142368次训练样本呈现；完整2987行轨迹和8064条测试预测全部保留。数据固定48/96/384划分，算法种子不等于独立数据集重复。

每项单独启用，没有同时加多种方法后混乱归因。错误增强故意违反标签规则；合法增强的正确性只对当前合成机制成立。标签平滑的一个Brier配对结果变差，均值差极小，不主张校准保证或统计显著。实验未搜索每个方法的最佳强度，不是普适排名。

手算固定两样本、九参数及具体掩码，完成逐样本前向、标量损失、每条局部导数、全部路径与梯度、同时更新、下一次前向；独立测试再覆盖两参数点×16掩码。其回归半平方目标与主实验分类CE是两个不同对象。
