# 037 正则化与数据增强实验指南

本实验将“单次运算正确”和“有限对照观察”分开核验。先重算带固定掩码的九参数小网络，再完整运行七个单独处理、三个配对种子的二分类实验。目标是判断一种方法改变了什么以及证据支持到哪里，不是找一个最漂亮的赢家。

## 1 交付文件与运行环境

experiment.py包含可独立调用的公式、模型和实验。test_experiment.py是独立测试文件，使用精确分数、逐坐标差分、PyTorch与独立NumPy实现相互核对。experiment.ipynb已经在新进程的全新IPython内核中逐格执行并保存输出；学习时仍请重启内核后运行全部。make_figures.py从经过摘要验证的数值文件生成13张原创图。

实际验证环境是Python3.12.14、torch2.7.1+cpu、numpy2.3.5、matplotlib3.10.8，CPU单线程、float64。environment.yml记录重建环境所需的直接版本；本次没有在所有操作系统上重新建立Anaconda环境，也没有GPU或混合精度结果。

在本单元目录运行：

```bash
python test_experiment.py
python experiment.py
python make_figures.py
```

脚本默认通过自身位置定位data和outputs，不依赖当前工作目录。也可以从任意目录传入脚本绝对路径：

```bash
python /your/path/units/037/experiment.py --output /your/path/new-run
```

相对的--output与--data-dir按当前工作目录解释。--epochs可用于学习者另做短实验，但短协议不能覆盖正文的完整结果；建议始终指定新的输出目录。绘图脚本只接受本次默认160轮、六个数值文件的已知SHA-256，修改协议后它会拒绝把新结果包装成原图。若研究上确需新图，应先建立新的结果版本和审核协议，而不是关掉校验。

## 2 数据来源与信息边界

全部数据为原创合成，不涉及个人数据或外部下载。生成器是NumPy default_rng(3700)。依次为训练48条、验证96条、测试384条生成两个[-1,1]均匀坐标，再独立抽取.15概率的标签翻转。干净标签是1{x1>0}，观测标签为干净标签与翻转位的异或。

CSV字段为id、x1、x2、y、clean_y、flipped。id全局不重复；y是训练与评价使用的观测硬标签；clean_y与flipped仅用于生成机制审计和图上的圈标记。切勿在训练时偷用clean_y，或删去已知带噪行后仍声称与当前实验同任务。

三份CSV是交付后的权威输入。read_data逐文件验证摘要、字段、行数、有限性、二分类标签、无交集ID、噪声标记与干净规则。失败会发生在结果文件创建或覆盖之前。自动重新生成一份“看起来相同”的数据不能代替摘要验证；不同NumPy版本的生成行为也不应被默认为逐位相同。

训练函数train_one只接收train和validation两份字典，签名中没有测试数据。run在所有21个训练与早停选择完成后才评价测试。虽然程序为了输入预检会提前读取并验证三份CSV，测试数值没有被传入训练、快照选择或超参数搜索；“文件已被读取”与“信息用于模型选择”是不同问题。

## 3 第一站 重算带掩码的完整链

在Notebook第二个计算环节打印hand_trace。先遮住gradient和updated_theta，只看以下固定值：X两行为(1,2)、(−1,1)，y=(.7,−.2)，W行分别(.5,−.2)、(.3,.4)，b=(.1,.2)，u=(.6,−.5)，c=.1，掩码两行(1,0)、(1,1)，保留概率q=.5。损失是两个半平方的平均，λ=.1只惩罚W、u。

按次序完成：

1. 算四个Z、ReLU门控和H，再乘固定M/q
2. 算两条P、残差、两项半平方、平均L、惩罚Ω及总J
3. 从平均因子1/2开始，列出输出、dropout、ReLU、仿射层的局部导数
4. 对九个共享参数分别加两条样本贡献与一条惩罚贡献
5. 使用旧快照的全部梯度同时做θ←θ−.05g
6. 用新九参数、原掩码重新前向，再将掩码换成正文指定的M′比较

首轮应得到P=(1.54,−.7)、L=.2389、Ω=.0575、J=.2964。更新后相同掩码下J约.1675555102。这里的下降只属于固定掩码；新掩码和eval的目标值不是同一个函数值。

test_fraction_all_parameters_paths_update用独立Fraction标量循环核验九参数路径与同时更新。test_autograd_all_masks_all_parameters对初始与更新后两个参数点分别枚举16张掩码，核对loss、输入梯度、全部九参数梯度与中心差分。测试不是只检查几条容易的非零路径，零路径也被保留。

## 4 第二站 精确枚举与模式探针

enumerate_masks返回16张掩码，每张概率1/16。逐行保存prediction、sigmoid_prediction、data_loss、gradient；同一参数的不同掩码不是不同训练好的模型，而是同一个共享参数网络的随机子图。

核对平均P=(.42,−.3)，与关闭dropout的仿射输出相同；平均半平方为.2317，关闭时为.0221，两者差.2096。再用每条样本的半方差相加除以2解释差值。sigmoid之后的均值则与对均值做sigmoid不同。

mode_probe使用真正的nn.Dropout，在train/eval与记录梯度/no_grad的四组合下运行。它还核验标签平滑的双精度软目标与PyTorch交叉熵一致。注意eval恒等返回可能保留输入的requires_grad=True；这不是新的运算图被no_grad记录。

主训练网络使用显式生成并传入的0/1掩码，实现相同inverted公式，以便逐步重建随机流；这不是声称它与nn.Dropout内部随机数生成算法产生逐位相同的掩码。官方模块用于核对模式和公式语义，主实验用于可审计训练。

## 5 第三站 七个单独处理

每次网络是2→24 tanh→dropout位置→24 tanh→1 logit，共697参数，无BN。初始化采用明确的输入输出维数尺度；偏置置0。AdamW学习率.01，betas=.9/.99，epsilon=1e-8，不使用调度。每轮3批，每批16条，上限160轮。

|处理|相对于基线唯一改变|评价快照|
|---|---|---|
|baseline|无，所有额外处理关闭|第160轮|
|early_stop|验证CE连续20轮未严格改善即停|恢复历史最佳，第0轮不候选|
|dropout|首层tanh后丢弃概率.3|第160轮，eval关闭随机门控|
|decay|三层权重AdamW衰减.1，偏置不衰减|第160轮|
|augment_valid|.5概率翻转x2，标签保持|第160轮，原始输入|
|augment_invalid|.5概率翻转x1，标签故意保持|第160轮，原始输入|
|label_smooth|α=.1向两类均匀分配|第160轮，硬标签指标|

三种子370、371、372表示算法重复，数据不重新生成。分别以seed+20000初始化，seed+10000重排，seed+30000产生dropout掩码，seed+40000作增强选择。随机流分离保证方法的额外抽样不会移动其他流的位置。配置间共享同一初值和重排，实现配对对照。

所谓“唯一改变”指预设处理及其由此产生的后续轨迹；数据梯度、参数、训练长度和预测当然可能随处理而改变。不是强行要求所有中间量相同。

## 6 早停的精确协议与成本

第0轮记录train/validation但不纳入早停候选。每轮训练结束计算原始硬标签验证CE，严格更小才更新best，复制参数并将wait清零；否则wait加1，达到20就停止。若直到上限都未触发，则也使用此前最佳快照。其他处理固定取末轮，不能从已记录的曲线中事后挑最低值。

|seed|最佳轮|停止轮|更新数|训练呈现数|
|---|---|---|---|---|
|370|17|37|111|1776|
|371|4|24|72|1152|
|372|5|25|75|1200|

全部运行8898次optimizer更新，共142368次样本呈现。非早停各次480步、7680呈现。实际验证前向次数记录在run-details：每轮后一次，加初始诊断一次，再加恢复/末轮终点重新评价一次，所以是epochs_run+2。该字段不包含训练集诊断、测试评价、网格推理、作者测试和Notebook重跑成本。

## 7 数值输出怎么读

六个输出文件各有明确职责：

- calculations.json：完整手算、下一前向、16张掩码与期望、四种模式、平滑框架核对
- training-history.csv：2987行，含第0轮，逐轮记录当前模型train/validation硬CE、错误率、真实更新数与样本呈现数
- ablation.csv：21行终点评价与预算、权重范数、增强选中和语义改变次数
- test-predictions.csv：8064行，即21×384，每条模型对每个固定测试ID的概率与硬标签
- run-details.json：版本、固定协议、数据摘要、21次完整末端或恢复参数及所有指标
- decision-grid.json：预先指定seed370、51×51网格、七处理的冻结预测面

training-history的stochastic_training_objective是每批更新前当前模型在该批变换/掩码/软目标上的CE，按样本数加权形成一轮平均。它混合一轮内不同参数快照；不是轮末模型在全训练集上的eval CE。对decay处理它不含显式L2项，因为优化器用的是AdamW解耦衰减。

所有主表train_ce、validation_ce、test_ce都是原始输入、关闭dropout、硬标签交叉熵。test_error用probability≥.5预测正类；test_brier为平均(p−y)²。不要跨列比较不同目标的数值，Brier也不是专门的校准误差。

## 8 独立核验与失败保护

运行test_experiment.py会执行15组测试。除手算外，独立NumPy网络给出697个参数的反向公式；所有21条训练轨迹都用独立前向、loss、增强、mask采样与AdamW递推重新构造，核对全部8898步之后的参数与每轮硬CE、早停选择、语义审计计数。测试记录允许极小浮点容差，不将平台位级差异等同于科学差异。

另有输入dtype/形状/NaN/标签值/概率/种子检查，错误CLI和缺失数据检查，以及损坏图来源时不覆盖目标图的检查。防护使用显式raise和unittest断言，不依赖会被python -O删除的assert。通过测试不意味着能安全执行任何陌生脚本；只应运行可信来源代码。

作者还在新进程执行normal、-O和无关当前目录三类脚本重跑，逐文件摘要对比。Notebook首格在import之前核对实验代码、测试、绘图代码、三份数据、六个输出摘要，防止另一个同名目录被误认作当前单元。所有代码格从清空内核真实顺序执行，最后在临时目录重做完整实验并比对六个数值文件，临时目录随后清理。

写文件时，程序先完成所有输入检查、计算和序列化，再逐文件临时写入与原子替换。单个文件替换是原子的，多文件一起不是断电事务。不要在运行过程中读取一半新一半旧的结果作为科研证据。

## 9 自己改实验时先写协议

建议先修改一个因素，使用新目录保留输出。若改为dropout概率网格，先冻结候选如0/.1/.3/.5、学习率规则、同样的种子集合与上限，再仅按验证指标选配置。公开所有候选和搜索成本；本讲测试已经被阅读，不能把它再次当作全新未见测试，应另生成并封存独立测试，或建立适合真实数据的外层评价。

若改数据生成规则使x2携带标签信息，原先合法的增强可能立刻变成错误。应先重做语义审计，再讨论效果。不要在看到曲线差后换标签定义并保留旧图题。

提交实验记录时回答：哪个机制已被精确核对，哪个结果只是有限观察；三次随机重复到底改变了什么；增强保留的任务性质是什么；真实更新预算是多少；哪些指标出现相反方向；还有哪些结论当前不能支持。
