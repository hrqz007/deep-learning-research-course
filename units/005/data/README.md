# 原创合成校准数据字典

数据全部由generate_data.py确定性生成，不下载、不含真实设备或个人信息。主任务为09:00使用两个旋钮预测09:05读数，目标是未用于训练的设备。两天实体留出不验证更远未来漂移。数字、错误案例及名单为教学构造，不是现实表现样本。

records_raw.csv有13行：A至F六台设备，2026-01-01/02各1次，追加A02完全相同副本。唯一观测键record_id，本案例业务键(device_id,predict_time)。设备重复不等于重复观测，相同输入不等于同一记录。

|文件字段|类型|单位及含义|允许缺失|角色|
|---|---|---|---|---|
|record_id|string|观测身份，A01等|否|连接与拆分|
|device_id|string|设备身份，A至F|否|分组，不进入主任务X|
|predict_time|ISO datetime|同一合成时区的09:00，无时区后缀|否|预测截点|
|knob1|finite number|格，09:00可用|否|特征0|
|knob2|finite number or empty|格，09:00可用|仅A02/D02空字符串|特征1|
|post_reading|finite number|09:05最终读数，读数单位|否|禁止进入X的泄漏字段|
|post_available_time|ISO datetime|同日09:05|否|晚到字段审计|
|target|finite number|读数单位，labels.csv内|否|标签|
|label_available_time|ISO datetime|同日09:05，labels.csv内|否|标签可用时间|

CSV只有knob2的空字符串被认可为缺失。文本NaN/inf或其他非法字符串被拒绝；允许空值进入数组时转换成np.nan。真实跨地区任务须另行明确时区；本例只比较相同时区的合成时间。标签文件按记录逆序存储，必须按record_id连接。

生成细节：设备序号k从0至5，天序号d为1或2，完整旋钮1为2k+d，完整旋钮2为10倍旋钮1。标签=2×旋钮1+0.1×完整旋钮2+1+设备偏移，偏移依A至F为[-2,2,-2,2,8,10]。A02/D02在导出输入时删去旋钮2；该完整生成值不授权给预测管线使用。post_reading与target完全相同，用来显式演示未来字段偷看。

entity_split.json固定训练A/B/C、验证D、测试E/F，共6/2/4条。time_illustration.json不是正式拆分：只有第一天训练、第二天验证的示意，明确第三天测试记录不存在。正式脚本只使用实体名单。

memorization.csv是独立的12行身份记忆反例，设备A至F各两次，标签依次固定为[2,5,11,17,29,43]。record_id唯一；visit为1/2；target单位为演示读数。它的两种拆分针对不同目标，误差差值不是一般泄漏效应估计。

原始文件保留重复与缺失，正式清理只在内存中进行。数据公开供学习，不是真正封存盲测。主脚本不计算主数据测试标签误差；全量错误均值和记忆反例单独标明，不能用于优化主流程。
