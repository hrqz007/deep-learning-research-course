# 固定合成训练问题

32行，无真实个人数据。对id i=0,…,31，x1=((7i mod17)−8)/4，x2=((11i mod19)−9)/5，y=.7x1−.4x2+.2x1x2+.03((i mod3)−1)。周期扰动不是独立同分布噪声的声称。CSV按原始浮点运算后17位有效数字保存，实验以固定字节为准。

order.json保存40个Python random.Random(320)生成的完整排列，每个含所有32个ID恰一次；运行时不重新抽样。所有批量方案使用同一1280索引流前缀，仅分组不同。这个优化实验是随机重排实现，不是假装独立有放回训练。理论里的有放回分布另由有限枚举和标量解析递推处理。

config.json保存13个初始参数、1280样本呈现预算、40步预算、批量1/4/16/32、基准学习率.02及dtype。参数顺序是W(3,2)逐行六项、b(3)三项、v(1,3)三项、c一项。损失为每样本半平方误差的均值。

本讲数据只用于优化机制，没有训练/验证/测试拆分或现实泛化指标。固定报告入口核对三个输入摘要；绘图/Notebook另外核对八份原始输出，其中计时是独立观测文件。哈希只说明字节身份，不证明实验设计合理。
