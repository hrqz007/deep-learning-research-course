# 合成绘图台数据字典

plotter.json 是本讲原创确定性教学数据。P01、P02、P03 是三条指令，无真实个人或设备数据。没有训练、验证、测试拆分，因为本实验不拟合参数、不报告泛化表现。

- X：形状 (3,2)，每行一条指令，两列分别为旋钮1、旋钮2电压，单位 V。
- W1：形状 (2,3)，输入特征在行，内部通道在列，单位 R/V。
- b1：形状 (3,)，每个内部通道一个共享偏置，单位 R。
- W2：形状 (3,2)，内部通道在行，输出坐标在列，单位 mm/R。
- b2：形状 (2,)，水平和竖直坐标共享偏置，单位 mm。
- R 是自定义响应单位；所有三条内部通道使用相同单位。W1、W2 及偏置固定给定，未由测量或优化估计。

本讲允许负电压及负坐标，是代数模拟器，不声称真实设备可达到这些输入。JSON 中 0.5 可被二进制浮点精确表示；泛化测试另用分母 3、5、7 的有理数检查容差。数据和实验代码一起固定，不在线下载。
