# 合成数据字典

全部数据由本课程原创构造，无真实机器、人员、机构或客户记录。固定的 24 条主记录用于展示评价流程，不用于估计现实性能。

| 字段 | 类型 | 含义 |
|---|---|---|
| row_id | 字符串 | 唯一记录标识；仅供对齐与去重 |
| entity | 字符串 | 合成机器实体；主表每实体两条记录 |
| time | 正整数 | 相对检查顺序，不是真实时间戳 |
| group | 字符串 | 合成子组 A/B，另有 panel 练习标识 |
| sensor | 0 至 10 整数 | 检查时可得的输入，固定分数为 sensor/10 |
| y | 0 或 1 整数 | 检查后得知的是否需要检修标签 |

train.csv：实体 E01 至 E04，time 1 至 8，共 8 条，2 个正例。
validation.csv：实体 E05 至 E08，time 9 至 16，共 8 条，3 个正例。
sealed_test.csv：实体 E09 至 E12，time 17 至 24，共 8 条，3 个正例；学习时请在方案冻结后才查看。
split_panel.csv：A/B/C 三实体，各有 time 1/2/3，9 条；标签恒为 0，因为这份表只演示拆分，不参与指标或阈值选择。

生成方法：直接列出这些有限记录，无随机抽样。标签和 sensor 的组合是教学构造，不是物理规律。A/B 子组也不代表现实人群。主数据的时间与实体双重隔离是刻意安排的；panel 数据用于展示这两种约束不能混为一谈。

校准和回归例以短列表直接写在脚本与 Notebook 中，数值与正文一致。它们与主告警数据相互独立，不应拼接为更大的评价样本。
