# 原创合成分类点

classification.csv有9训练点和6固定测试点。字段id唯一，split为train/test，x1/x2为无物理单位的坐标，y为0/1/2互斥类别。训练3点/类，测试2点/类。矩阵最后的常数1由程序追加，不在CSV重复保存。

config.json预先固定400步、学习率0.25、特征L2系数0.03，测试从未用于参数或步数选择。正文0.3手算是独立的一步演示。另一个一维无正则可分例直接在代码定义x=(-2,-1,1,2)、y=(0,0,1,1)，不要将其结果当成三类实验。

数据是人为设计，不是从真实总体IID抽样；无个人资料、下载或付费API。固定图与Notebook要求这些默认输入及五份默认输出摘要相符，自定义结果另存。
