# 完全已知的合成总体

X均匀取0到7。x小于4时Y=1概率1/10，其余为9/10。先从8个输入编号均匀抽一个，再从10个标签机制编号均匀抽一个。等价的80个联合原子使总体风险可精确计数。此机制、标签与模型不来自任何真实人群。

hand_training.csv的4条记录为固定手算反例，包含允许出现的少数标签，不是模拟中选择出的最好或最差一次。sample_id只是本文件记录编号，不把相同x的不同独立生成标签合并为同一人；本课没有真实实体。训练时可以出现同一个x上的冲突标签。

config.json定义800次重复，训练量8、32、128，验证32、测试256。每个重复重新独立生成三批，分别用于拟合、选择、冻结后评价。三种候选使用同一训练批与评价批；类别选择不读取测试标签或总体风险。伪随机局部实例与运行版本用于复现，不能当真实独立性证明。

outputs/trials.csv逐条记录9600个“样本量×重复×候选或选中模型”结果；模型与数据由所记seed、配置、固定生成器和Python版本重现，不另存大量原始重复样本。summary.csv有12行。图和Notebook固定对应默认配置、原始手算表及相应结果；改变输入后须将自定义脚本结果另存，不复用固定图文。
