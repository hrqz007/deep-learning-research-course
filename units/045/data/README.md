# 045 原创数据与重放计划

images.json中train、validation、test分别为48、48、128幅8×8单通道图，种子4501、4502、4503。0类为竖条，1类为横条，各占一半，条长4、宽1，中心相关整数位置在3与4中取值。前景0.95，原背景0.15（类0）或0.75（类1），加独立Gaussian噪声std0.025，不裁剪数值。mask、boxes、background、noise全部保留。

x是原相关视图，swapped按明确公式将背景改为1-background（0.85/0.25），neutral将背景改成0.45。三视图共享形状、位置、噪声，是同一图像的配对干预，不是三个独立对象。所有图、掩码和标签均原创，不含真实个人或外部图片。

augmentation_plans.json用初始化seed+1000的独立NumPy生成器为每个seed保存160×48个背景Uniform[.1,.8]值和旋转Bernoulli(.5)标志。两旋转臂共享完整图像，只改是否交换方向标签。前景掩码用于训练背景重采，属于已知合成额外信息，不假定真实应用自动有同样掩码。

标签与背景在原分布完全相关是刻意设计。条长为偶数且位置有限，使旋转后的方向/空间相位分布不完全对称；它不是保证错标签臂严格50%的理想对称数据。保持原数据和全部结果，不事后修饰分布。

protocol字段冻结模型、步数、学习率与比较。data_manifest.json覆盖数据原字节。重新生成建议python generate_data.py --output generated-data；默认会覆写目标目录同名文件。参考NumPy2.3.5，跨版本逐字节一致未保证。公开标签和生成器用于教学，不是长期盲测。
