## 3 坐标与插值小任务

先构造一幅2×2 RGB图，手动指定一个像素的三个颜色值。把HWC用transpose变成CHW，再试一次错误reshape；画出结果并定位哪一个颜色数值跑到了错误位置。检查shape不足以验收。

接着复现4×6的裁剪/翻转实例。原主框[1,1,5,3]，另一个框[0,0,1,1]，裁剪(top,left,height,width)=(1,2,3,4)。先把框减去裁剪原点，再裁边、去除零面积框，最后翻转。主框应变为[1,0,4,2]，面积保留0.75，原第二框应通过keep_indices被识别为丢弃。

用变换后mask中所有非零像素求最小/最大行列，最大索引加1，核对它与半开框吻合。这是独立的像素级参照；不能只拿同一个框变换函数跑两遍比较。

把数值图[[0,1],[2,3]]从2×2变到3×3，手算中心值1.5。再把类别图[[0,2],[2,0]]用双线性变换，解释中间的1为何不是合法ID。最后用最近邻检查类别集合仍为{0,2}。

## 4 支持域与明确失败

normalize接收CHW浮点或可转换实数，以及长度为C的一维mean/std；std必须正且有限。resize_bilinear固定半像素、边缘夹取、align_corners=False、antialias=False；resize_mask只接收二维整数ID，采用nearest-exact中心约定。

crop_flip要求裁剪完全位于图内，mask尺寸匹配且为整数，boxes为K×4合法半开XYXY，允许空框列表。flip必须是布尔值。非法框、非有限数、空图、非正尺寸/尺度和超过图像资源上限应抛错。不要用关闭检查来让错误数组“能训练”。

以下例子先预测shape与坐标，再运行：

```python
import numpy as np
from experiment import crop_flip
x = np.arange(24.).reshape(1, 4, 6)
mask = np.zeros((4, 6), dtype=int)
mask[1:3, 1:5] = 2
boxes = np.array([[1, 1, 5, 3], [0, 0, 1, 1]])
r = crop_flip(x, mask, boxes, (1, 2, 3, 4), True)
print(r['image'].shape, r['boxes'], r['keep_indices'])
```

预期image为1×3×4，剩余框只有一个，保留原索引0。框面积保留比例与真实前景可见比例并非一般等价，只是在这个矩形实例里可以直接核对。

## 5 完整手算与独立梯度证据

复制讲义两幅2×2图，标签按原始空间均值计算。依次填写原始像素、翻转后像素、归一化值、仿射预测、残差、损失。把每条局部导数写出来，尤其是样本平均1/2、归一化1/std=2与翻转的反向置换。

按五个共享参数分别累计两样本贡献，再一起更新，保留同一增强重算下一次前向。不得先改某个权重、再用新权重算同一旧图的输入梯度。记录三次平均损失约0.10644531、0.07969513、0.05980188。

测试把Fraction精确账本与Torch核对，输入导数把标签固定。另对主CNN写NumPy滑窗/收缩式反传，并对全部297参数作中心差分。这里参数初始化让测试点远离ReLU拐点；若自己更改后接近0，先解释非光滑性，而不是把每次差异都当框架错误。

## 6 四臂协议与重放

四臂为不增强、只换背景、换背景加旋转但保留错标签、同样换背景旋转并交换标签。三个初始化种子下四臂共享初始参数，两个旋转臂更共享每一步的实际图像，只改标签。每次全48图、160步、学习率0.2，网络297参数，无早停、dropout、BN或调参。

任选一个在计划中rotate90=1的记录，记下种子、步号和样本号。先重采背景，再旋转，再用训练尺度归一化；重复调用应该得到同一数组。错误与正确旋转臂图像应该完全一致，标签应该在发生旋转时不同。

证明背景重采只影响mask=0处：逐像素比较前景差为0。注意它依赖真实掩码和原背景值，这些信息由合成生成器提供；报告中必须披露，不能把它包装成无需分割信息的通用真实图像增强。

## 7 运行全部实验并读懂结果

experiment.py真实执行12次训练，保存1920次更新与1932个参数状态。每个状态有参数、偏置和（除最终状态外）该步增强批次损失；training_traces.json.gz保存完整轨迹，results.json给出解压原文与压缩包摘要。

检查三个训练种子与四臂都存在，不能只保留最好一条。核对总训练呈现数12×160×48=92160。validation只提供原相关条件的描述，没有决定训练步数；test三个视图在固定训练结束后评价，不作方案筛选。

至少把下列事实写进报告：无增强原相关100%而反相关0%；背景增强修复这个失败但提高原相关NLL；正确旋转并未在所有NLL上胜过仅换背景；错标签臂各种子差异很大，也不是必定50%。

解释最后一点时先检查生成器的方向/位置支持与偶数条长相位，不要事后换数据以追求预期答案。三个种子是算法重复，不是三批独立现实数据；本实验只给描述性读数，不冒充普遍因果证明。
