# 原创合成导数夹具

batch.csv有5条无量纲合成数据，非真实人群或任务样本。id唯一；x1与x2为输入特征；y为三类索引0、1、2。这里只测试求导，没有训练/测试拆分，没有对真实任务表现的推断。

config.json固定三个仿射层：2→3→2→3，两个tanh隐藏激活，输出为3个logits。共26个独立标量参数。初始数值手工指定，不来自训练；fd_h=1e−5，learning_rate=0.1仅用于一次更新示例。

CSV必须保持id,x1,x2,y四列，1到128条记录，id为非空唯一ASCII字母数字/下划线/短横线字符串，y为非负整数文本且在输出类别范围内。特征绝对值不超过10，拒绝NaN、无穷以及非零文本转为float64零的值。

数学API支持1至5个仿射层，每层宽度1至16，输出至少两类，参数绝对值不超过10；CSV入口固定两个特征。相邻层shape必须连接，偏置为一维数组；激活只能tanh、relu、linear。fd_h范围1e−10到1e−2，学习率1e−6到0.5，不接受布尔值。自定义参数可能导致扰动越界、饱和或单步不下降，不承诺配置合法即差分通过。

修改数据或配置时另存文件，并用--data、--config、--output指向独立实验目录。固定Notebook和图的入口会核对默认两份输入及五份输出摘要，拒绝把原讲解套到修改后的结果。数学计算允许浮点舍入与计算期下溢；入口前已经丢失的信息无法恢复。
