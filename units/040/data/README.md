# 040 合成数据与冻结协议

本目录不含个人数据或第三方受限数据。generate_data.py为原创生成器；运行时明确指定--destination，可在另一目录再生train.csv、validation.csv、test.csv并比较摘要。

三个拆分分别由NumPy PCG64 default_rng种子4040、4041、4042独立生成。样本数48、128、512。X独立均匀分布于[-3,3]；条件均值为0.8*tanh(1.3*x)+0.25*sin(3*x)，噪声是独立标准正态乘以sigma，x<0时sigma=0.1，否则0.35。每个拆分先一次生成全部x，再一次生成正态噪声。CSV浮点使用17位有效数字，UTF-8，换行固定LF。

字段id为跨拆分唯一的公开合成ID，x为单一数值输入，y为有噪标签，group由x的符号确定（left或right）。group用于预先定义的描述性误差报告，不参与模型输入或标签选择。没有缺失值；不包含真实人物或敏感属性。

训练均值和总体标准差仅在实际使用的训练子集上估计。主搜索用全部48例；tiny_probe用前8例，overfit_probe用前16例，因此各自重新拟合训练归一化。验证与测试只复用相应训练参数。不同探针的宽度、数据量和预算明确不同，不作为同预算排行。

protocol.json是固定可执行教学计划，涵盖网格、初始化种子、诊断、停止、选择、部署集成与配对bootstrap。它不是外部时间戳预注册。fixture-hashes.json保存三个CSV摘要；experiment.py还固定协议和CSV摘要，防止无意混用版本。测试文件提前接受字节完整性核验，测试标签在默认程序中只进入最终冻结比较；公开文件不能物理阻止后续人为调参。

hand_chain.json中的两样本七参数手算独立于这些随机数据，不应拼进训练集。
