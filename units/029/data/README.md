# 固定合成数据

batch.csv与027的原始五条合成样本逐字节相同，标签为0、1、2、1、0。config.json与027原始配置逐字节相同：2→3→2→3、tanh隐藏层、26参数、差分参考步长1e-5、单步学习率0.1。

本讲不把五条数据当训练/验证/测试效果证据，而把它们当同一计算在不同实现中的迁移探针。没有真实个人数据，没有网络下载。运行入口只接受两份固定文件，修改字节会拒绝，防止原图和新数据混配。自定义探索使用函数并保存到其他文件。

figure-input-sha256.json列出两份输入和五份默认结果的摘要，供图与Notebook入口检查。它不包含任何私有文件路径，也不证明数学正确；数学正确性另由手算、独立参照、差分和失败案例检查。
