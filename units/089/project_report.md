# DL089 研究短报告

## 问题

受控视觉问答的高分来自图片、问题还是提示？视觉证据遮挡与文字建议冲突是否能区分这些路径？

## 方法

原创8×8 RGB双区域场景，颜色红/蓝，问题问左/右。固定空间平均形成2个5维视觉token。训练提示约95%正确。比较文本单模态、图像单模态、拼接、偏置提示交叉注意力、随机提示交叉注意力。五方法各三种子，300步、批量96、Adam学习率0.01。三份独立数据为960/240/480条，八个测试域由同一480条配对生成。没有模型选择或早停。

## 结果与解释

文本单模态原域93.33%、冲突提示0%，展示文字捷径。图像单模态原域73.96%，接近均衡生成条件下不知道问题的75%最优期望。拼接原域99.72%、冲突97.71%；两种交叉注意力在完整图像冲突域均100%，不支持随机化在该指标进一步优越。

目标遮挡仍保留提示时，偏置注意力73.75%、随机提示注意力50.28%。两者在目标遮挡且无提示时都约50%。差别反映对剩余提示的利用，不能直接决定谁更鲁棒。当前模型只有二分类，无拒答，不测开放生成幻觉。

图像单模态在另一侧遮挡达100%，因为遮罩根据问题制作，留下区域透露目标位置。这一强诊断条件不能与原域当成同等输入权限。

## 验证和预算

七组参数有限差分误差均低于10⁻¹¹；15份权重重载概率差0；18项测试普通与优化模式均通过。15模型4500步、432000条样本呈现，完整时间见JSON。不同结构参数量114至274，不声称严格等参数或等算力。

## 边界

固定平均池化、one-hot问题、两类答案与已知全部组合都远离真实大型VLM。可支持的结论是当前生成器上的信息路径诊断，不能推广为开放语言理解、视觉幻觉治理或真实场景安全保证。下一步应针对池化丢失的信息设计配对反例，而非随意加大模型。
