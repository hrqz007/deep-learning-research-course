# DL089 实验与研究任务

本实验真实训练五种小模型，观察答案究竟来自图片、问题还是提示。它是二分类视觉问答，不是大型语言模型复现；不要把结果改名为通用VLM成绩。

## 1 重跑与证据

在可写目录中安装并执行：

```bash
python -m pip install -r requirements.txt
OPENBLAS_NUM_THREADS=1 python experiment.py
python -m unittest -v test_experiment.py
```

Windows PowerShell可先执行$env:OPENBLAS_NUM_THREADS="1"。默认脚本会覆盖当前单元outputs的同名结果；需要保留发行快照时，先复制目录。Notebook的新结果保存到notebook_run，不覆盖发行快照。

检查15份权重、120行指标与57600行逐例预测：5方法×3种子×8域=120，120×480=57600。确认results.json的reload_max_error为0，梯度最大误差低于10⁻⁶，环境和训练参数均有记录。

## 2 shape练习

画出8×8×3图像如何变成2×5视觉token，注明3维颜色与2维位置各自来源。然后列出：问题输入、W_Q、Q、W_K、K、W_V、Value、注意力矩阵、读取向量、答案头输入的形状。

解释为什么“视觉投影到语言宽度”不改变视觉token数。计算768→4096线性投影带偏置的参数总数。若视觉token数为64，文本token数128，比较交叉注意力与统一全注意力每头分数元素数，并写出不包含的成本。

## 3 手算交叉注意力

q=(1,0)，左键(0,1)，右键(2,0)，d_k=2；左值(1,0)，右值(0,1)。计算缩放分数、注意力权重、读取向量。再令两个键相同，观察结果。最后令两个值相同，说明为什么注意力变化不必改变输出。

## 4 检查梯度和模型确实训练

运行gradient_check，检查七组参数：w1、b1、w2、b2、wq、wk、wv。说明每组参数对应哪个计算步骤。

在独立副本中把softmax沿区域轴改为跨批次归一化，观察权重和、梯度测试或训练表现会怎样变化。这个故障版本不可混入正式结果。解释为什么批内其他样本不应参与当前图像的视觉读取。

## 5 先预测单模态表现，再看输出

不用运行代码，证明原域图像单模态的75%理论最优期望：左右同色与异色各占多少？缺少问题时各能达到多少？这个结论依赖什么独立性与平衡条件？

解释文本单模态为何原域可达到93.33%，而在必错提示下是0%。把“提示与真值高度相关”与“把答案数组直接传入模型”区分开，指出前者虽不是实现泄漏，却足以让评测误导。

## 6 成对观察八个测试域

固定一个左右异色的sample_id，查看原域、冲突提示、目标遮挡、目标遮挡且无提示、换问另一侧的输入与预测。记录每个域究竟修改了哪些字段，以及是否需要修改正确标签。

特别回答两题：

1. 目标遮挡保留原提示时，模型准确率高是否证明它仍看到了颜色？
2. 图像单模态在“另一侧遮挡”达到100%，为何不是它突然理解了语言问题？

正确答案必须涉及剩余信息和遮罩的生成规则，不能只说“模型更鲁棒”或“注意力更集中”。

## 7 审查实际结果

从metrics.csv重算五种方法在八域的均值与样本标准差。对两种交叉注意力的冲突提示准确率作配对比较，说明实验是否支持随机提示训练在此指标更优。

比较目标遮挡与目标遮挡且无提示。讨论为什么随机提示训练的较低遮挡准确率不能直接判为算法失败：部署任务是根据任何有用线索预测，还是必须基于可见图像回答？当前分类器没有拒答选项，这会怎样限制解释？

不要把三种子标准差当作现实人群泛化置信区间。八个测试域来自同一480个基础样本，统计时应保留配对结构。

## 8 设计一个新的信息瓶颈实验

任选一项，先写协议再运行：

- 每半区放两种颜色，问题问“上方”，检验当前平均池化是否已经丢失垂直位置
- 增加四个空间区域，比较相同token预算下的池化与选择
- 扫描训练提示可靠率，但提前固定测试域与完整报告的所有值
- 引入拒答输出，在独立验证集定阈值，再报告覆盖率与接受样本风险

协议需包含输入字段、信息是否保留、单模态基线、数据分区、所有种子、主要指标、预算、失败条件及干预是否泄漏额外选择信息。未运行的扩展只能作为计划，不能写成结果。
