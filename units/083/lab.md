# DL083 实验：看见适配收益与遗忘

## 实验问题与交付物

假设：在真实领域改动秩为2的合成条件模型中，低秩分支可以用更少可训练参数降低新域损失，但未必保留旧域能力。交付冻结、全量和秩1/2/4的比较，包含新域NLL、旧域NLL、准确率、参数数目和合并误差。不要把本实验称为Transformer微调。

## 1 环境与预检

在本讲目录用Python 3.12创建虚拟环境。联网安装依赖仅在准备阶段需要；实验本身无网络请求。

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python experiment.py
python -m unittest -v test_experiment
python -O -m unittest -v test_experiment
```

Windows可使用.venv\Scripts\activate。若只运行数值实验与测试，安装NumPy即可；PDF和Notebook依赖用于完整教材再生成。机器无需GPU。确认当前目录含experiment.py，再运行，避免导入别的同名文件。

## 2 先做不训练的检查

调用fixture，写出七个返回值的含义：训练输入及标签、适配测试输入及标签、保留测试输入及标签、原始权重。形状应为(240,12)、(240,)、(120,12)、(120,)、(360,12)、(360,)、(8,12)。打印softmax各行之和，应接近1。

手算W有96个数，秩2的A与B共有24+16=40个数。不要把40直接叫“总模型参数”；原来的96个冻结数仍然要保存和计算。改变第一个输入特征的符号，检查它表示不同领域，而非真实自然语言token。

## 3 验证损失与掩码

调用loss_grad，先用全部样本，再让前7个位置掩码为1、其余为0；结果应等于仅传入前7条样本的损失。全零掩码应报ValueError，而不是产生NaN后继续训练。这个小测试映射到真实SFT里的“一个批次没有有效答案token”错误。

读test_gradient：它用中心差分检查三个W坐标。请再添加一个坐标并运行。若失败，先检查softmax归一化方向、标签索引和分母，不要先放宽容差。浮点误差应是解释后的剩余，而不是默认借口。

## 4 观察LoRA第一步

在交互会话创建随机A与零B，计算G、dA、dB。预期dA全零，dB通常非零。把A也置零，再算两个梯度，确认全部为零。这个操作是诊断练习，不要把双零初始化写回正式训练配置。

检查train内先计算dA和dB，再修改A与B。若先更新B再计算dA，便不再是同一旧参数点的同步梯度下降。复制错误实现到临时文件作对照，不修改正式版本，以免污染已验收结果。

## 5 完整训练与读取结果

experiment.py会保存metrics.json、history.json和weights.npz。冻结只做一次前向诊断，其他方法700次全批次更新；每20步记录一次训练损失。没有验证集调参，所以结果是一个固定教学协议，而非已调优模型排名。

先比较冻结与全量的新域NLL：本次约1.967与1.457。再看旧域：约1.663与3.281。写一句包含收益与代价的结论，例如“在当前合成拆分中，全量适配改善新域概率质量，但旧域NLL明显增加”。不要只抄新域最好的一列。

读取merge_max_abs_error，确认LoRA两路计算与合并权重计算一致，容差可取10⁻¹²。读取delta_rank，核对它不超过选择的r。查看训练参数字节字段时，注明float64每数8字节且不包含总进程内存。

## 6 独立扩展：数据量与秩的交互

先提出预测，再运行：训练样本减少时，秩4是否更易过拟合？使用固定测试集，将训练前60、120、240条分别训练；每个条件保持自己的训练样本嵌套关系。不要根据测试结果重新选学习率后仍称测试独立。

若要正式选择超参数，从原训练部分划一个验证集，用验证集选学习率、秩和停止点；最终测试只运行锁定方案。多种子应重新生成训练世界或明确仅重抽初始化；这两种重复测量回答不同问题。

## 7 故障排查

- 损失NaN：检查输入有限、稳定softmax与有效掩码总和。
- LoRA不学习：检查A、B是否双零，梯度是否误用转置。
- 底座改变：检查原地更新和数组别名，测试要求输入W₀不变。
- 训练损失改善但测试恶化：先考虑过拟合，不把它自动当实现错误。
- PDF缺字：安装Noto CJK字体后重建；数值实验不依赖字体。

## 8 验收

13项unittest应在普通和优化模式均通过；Notebook每个代码单元有真实执行编号且无error输出；合并、梯度和冻结检查通过；结果包含旧域保留评价；报告明确模型规模、数据来源与不能外推的范围。至少写一个反例：少参数不保证少总内存，或低秩不保证无遗忘。
