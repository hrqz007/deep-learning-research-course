# T5 合成数据字典

全部数字无业务单位。训练600条种子7701，测试400条种子7702。U、εx、εy、εz独立高斯，标准差1、0.4、0.2、0.08。X=U+εx；Y=2X+3U+εy；Z=Y+εz。Z为刻意的事后代理，提前预测任务中不可使用。

| 文件/字段 | 形状 | 含义和角色 |
|---|---|---|
| data.npz/train_x,test_x | (600,2),(400,2) | 列0=X，列1=Z；仅训练表用于训练 |
| train_y,test_y | (600,),(400,) | 实际生成的Y；测试只评价 |
| train_exogenous,test_exogenous | (600,4),(400,4) | 列U、εx、εy、εz，网络不读取 |
| do_x0,do_x1,y0,y1,z0,z1 | 各(400,) | 固定同一外生变量的成对干预，X设为−0.5或0.5 |
| weights.npz/p0,p1,p2,p3 | (2,12),(12,),(12,),(1,) | W、b、v、c真实训练参数 |
| predictions.npz/test_prediction | (400,) | 测试预测 |
| original_igs | (80,2) | 前80个测试输入相对零基线的128段IG |
| trace | (19,2) | 固定记录的[步数,均方训练误差] |

results.json保存查询点512段IG、两种基线、完整性误差、两级参数随机化、四级Z扰动、观察/调整回归与结构do效应。点归因使用512段，聚合随机化探测使用128段，二者不要混称同一积分预算。
