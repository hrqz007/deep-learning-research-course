# 原始来源与证据范围

核对日期2026-10-06。前三项是作者原论文，第四项是官方统计手册。所有本课数据、计算与图为原创实验，没有使用论文结果充当本次分数。

1. Holistic Evaluation of Language Models。https://arxiv.org/abs/2211.09110 。用途：多维度评价与场景，不代表运行HELM。

2. TruthfulQA: Measuring How Models Mimic Human Falsehoods。https://arxiv.org/abs/2109.07958 。用途：事实性需要单独测量，不代表运行TruthfulQA。

3. Judging LLM-as-a-Judge with MT-Bench and Chatbot Arena。https://arxiv.org/abs/2306.05685 。用途：模型裁判偏差，不代表已经有裁判分。

4. NIST 7.2.4.1 Confidence intervals。https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm 。用途：Wilson比例区间公式与边界。
