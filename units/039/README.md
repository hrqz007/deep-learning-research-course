## 运行

实际环境：Python3.12.14、torch2.7.1+cpu、numpy2.3.5、matplotlib3.10.8。CPU单线程、float64。environment.yml给出依赖配置；本次没有重新求解全新Anaconda环境，也没有运行GPU或Jupyter浏览器UI。

```bash
python test_experiment.py
python experiment.py --output my_run
python make_figures.py
```

不带--output时实验写本单元outputs。建议另写新目录保留参考。默认数据按脚本位置定位，可从无关工作目录绝对路径运行；显式相对--data-dir与--output按启动工作目录解释。--epochs 20可冒烟检查，正文的完整协议是240轮。

Notebook支持从039目录或包含units/039的仓库根启动；其他位置先设置UNIT039_DIR。首格在import之前检查三份代码、三份CSV与七份结果摘要。完整重跑写临时目录并逐个比较七份数值输出摘要，避免隐藏会话状态。代码或数据更改后摘要失败是预期保护，应为新的研究版本重新验证。

make_figures.py同样先核验结果摘要，不接受短协议或被修改的结果覆盖正文图。图重建使用可用的Noto CJK字体，其他机器请配置中文字体；现成PDF包含字体。程序显式检查NaN、形状、标签、非法权重/阈值/轮数；-O不会关闭这些检查。输出仅保证单文件原子替换，多文件不是断电事务。

## 有限结果

三种训练方法×三个配对初始化，共2160次SGD更新、518400次样本呈现、54000行测试预测、162行分组指标。所有配置保留，无挑选最佳种子。温度只用200条校准验证记录，阈值只用另外200条决策验证记录；全部选择结束后才解析测试标签。

温度改变概率质量但保持相应.5预测；行动阈值改变混淆计数但不改变概率评分。加权输出不能直接当原始概率，先验修正具有明确假设；单纯温度无法一般地替代logit平移。raw_temperature失败对照显示测试NLL改善时ECE仍可恶化。

本讲使用240/400/1000条固定合成拆分及25参数网络，不代表真实任务或大模型表现。算法种子不等于独立数据重复；不主张显著性、全组校准保证或普适最佳方法。作者核验与独立QA是不同步骤，verification.json不冒充独立验收结论。

数值边界：float64转换后再次拒绝非有限值；归一化加权风险先共同缩放权重以避免权重和溢出。按样本数归约若风险超出float64有限范围则报错。完整概率局部导数手算账本额外限制参数绝对值不超过1e6、logit绝对值不超过30；稳定BCE仍支持其声明的较大logit范围。

温度求导采用按标签稳定残差，并对单调的全正确/全错误方向明确取界；混合方向的浮点梯度全零时记录numerically_flat。极端logit镜像行为有普通/-O回归测试。
