# DL085 实验：偏好优化与裁判捷径

## 问题与假设

如果训练偏好中的正确性与冗长高度相关，策略能否在二者冲突时仍选择正确候选？比较参考、SFT、三个beta的DPO及偏置裁判DPO。此处“回答”是两个特征表示的候选，不是自然语言文本；不要把结果称为真实LLM后训练性能。

## 1 建立环境

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python experiment.py
python -m unittest -v test_experiment
python -O -m unittest -v test_experiment
```

核心仅需NumPy，完整环境支持Notebook、图和PDF。实验生成preferences.npz、weights.npz、history.json及metrics.json，离线运行，无GPU、付费API或外部标注者。

## 2 看懂数据再优化

训练400对，X两列分别为正确性差c和冗长度差v，均取−1或+1。y=1表示选择第一候选，y=0表示第二候选。普通标签按σ(2c)抽样，不是完全确定真值。95%训练对中，正确与冗长方向一致。

测试分三组，各1000对：相关性0.95、0.5、0。后者总把正确与冗长方向放在对立面。打开数据字典，确认训练与三个测试种子不同。测试标签反映模拟标注者；独立事实正确性来自c，评价时不能混用。

## 3 起始目标与手算

参考w=[0.8,0]。将它传给DPO objective，所有参考校正分数差都为0，因此损失log2。把method换成sft，损失一般不同；SFT直接看当前候选概率，不减参考。

手算一对参考概率0.2/0.4，当前0.3/0.3，beta=0.5。相对比率为2，z=0.5log2，损失约0.5348。把胜负次序交换同时把标签取1−y，目标应相同；test_pair_swap专门检查这一点。

## 4 梯度与稳定性

读取test_gradient，对SFT和DPO的两个权重分别做中心差分，容差约10⁻⁸。把权重变成[1000,−1000]，损失应保持有限。原因是实现用logaddexp而不是直接exp大数。beta≤0应拒绝。

若目标下降但梯度检查失败，不应继续调学习率。先核对beta乘法、参考减法、标签方向和平均分母。参考在训练中固定不动，本实验只更新两维w。

## 5 完整比较

读取不同方法的weights。观察偏置裁判版本的冗长权重超过正确性权重，这会使冲突任务选择错误候选。普通SFT和DPO的结果不能只用贪心正确率比较，因为它们在本例贪心都正确，却分配了不同概率。

主要看sampled_correctness，它是按模型分布计算的期望正确率，并没有真的随机抽取一次回答。另看annotator_agreement、mean_reference_kl、mean_verbose_probability。每个指标先写一句定义，再解释数值。

## 6 独立评价揭露自证

偏置裁判DPO的训练标签总选更长候选。它可能对该裁判几乎完美，却在冲突组贪心正确率0，采样正确率约0.138。把这一点写成一个失败案例，说明训练奖励和事实标准分离的重要性。

不要把偏置裁判版本与普通DPO的差异都归因于算法，因为标签生成机制也变了。这个对照研究的是同一种目标在不同偏好来源下的风险，不是不同算法排行榜。

## 7 研究扩展：相关性扫描

将训练correlation设为0.5、0.8、0.95、1.0，每种条件预先指定多个种子，保留相同冲突测试。预测完全相关时是否更难识别真正规则，再用权重与测试验证。不要根据冲突测试结果选最有利训练种子。

本次beta扫描固定600步和学习率0.3，只是教学敏感性检查。若要比较最佳性能，先划验证集，给各beta相等的搜索预算和停止规则，再锁定测试。观察loss下降速度与KL变化，避免把未收敛状态误解为理论正则关系。

## 8 验收

13项测试普通及优化模式均通过；Notebook实际内核运行；DPO起点log2、对调不变性、梯度与KL非负都核验；报告至少包含同分布和平衡/冲突测试、普通与偏置裁判、事实与标注两种指标。明确两候选简化、可见正确性特征、无自然语言生成和无现实安全结论。

若某方法训练损失改善、独立事实下降，这可能正是研究发现，不要删除“难看”结果。答案见answers.md。
