# DL088 实验与研究任务

本实验在CPU上从随机初始化训练两个线性编码器。你需要亲自检查“语义正确但配对失败”的例子，而不只是看到程序结束。默认运行不需要网络或API。

## 1 干净重跑

把本单元完整复制到一个可写目录，安装requirements.txt，运行：

```bash
python -m pip install -r requirements.txt
OPENBLAS_NUM_THREADS=1 python experiment.py
python -m unittest -v test_experiment.py
```

Windows PowerShell可先设置$env:OPENBLAS_NUM_THREADS="1"，再运行python experiment.py。训练、数据与图表全部在当前单元内部生成；第一次默认重跑会覆盖outputs中的同名结果，若需保留发行快照，先复制整个目录。

Notebook提供独立重跑入口，把新结果放到notebook_run，不覆盖发行outputs。它仍真实运行训练；已执行输出不是用静态表格冒充训练。依赖版本、运行用时、各方法与种子都保存在JSON。

验收：3种主方法×3个种子，共9份主实验权重；另有2次单种子温度诊断指标。data.npz含三份数据，metrics.csv有9行，predictions.csv有3888行。两方向×216查询×9模型=3888。检查reload_max_error均为0。

## 2 一页纸手算

任务A：a=(3,4)、b=(4,3)。计算点积、范数与余弦；把a乘10以后，哪些量变化？

任务B：余弦分数为(1.0,0.8,0.1)，分别用τ=1、0.2、0.05计算softmax，保留至少四位小数。解释为什么固定向量时改变温度不改变Top-1排序。

任务C：S=[[2,0],[1,0]]，正确配对在对角线上。分别计算图到文、文到图和双向损失。请明确每个分母沿行还是沿列。

任务D：一个查询有四个等价正例，目标在正例上均匀。若模型正好预测该目标，损失是多少？为什么不是0？

## 3 检查真实梯度与训练

打开objective，给每个中间变量写shape。依次核对XW_i、TW_t、UVᵀ、G_SV、G_SᵀU、XᵀG_Hi。说明单向图到文损失为何也更新文本塔。

运行finite_difference()，记下三种目标的最大绝对误差。将归一化反传中的投影项暂时删去，在另一份副本上再次检查，观察误差变化。不要把故障版本的结果覆盖到发行目录；完成后恢复代码。

比较初始权重与训练后权重，确认两个矩阵均改变。检查训练损失不是NaN，权重重载后的相似度与保存前一致。只打印“training done”不能证明发生了有意义的参数更新。

## 4 阅读检索失败，不混淆两种金标准

从predictions.csv分别找以下两类记录：

1. pair_correct=0且semantic_correct=1
2. semantic_correct=0

第一类至少展示一张查询图、其原配对文本与Top-1文本，并解释为何Top-1可接受。第二类若某方法没有出现，请如实记录“本方法此域未找到”，不能捏造失败案例；可检查单向或双向的其他种子。

为一个查询列出前五候选及语义类，重算pair R@1、semantic R@1、R@5和该查询的倒数排名。注意稳定索引并列规则；不要手工把原配对挪到并列第一位。

## 5 假负样本与重复审计

计算训练集非对角候选总数432×431，同类非对角项432×23，以及它们的比例。再计算B=72时每个查询预期同类竞争者数。验证audit字段与手算一致。

读取图像哈希重合数、文本跨集重复数与最近图像余弦。写一段200字说明：为何文本重复可以符合当前实验目标，却不能支持新句式泛化；为何图像高余弦并不自动证明泄漏；真实照片库又应怎样按原图或拍摄事件分组。

## 6 公平比较与结果表

用metrics.csv重算9次主实验均值和样本标准差。对同一seed计算双向减单向的图到文语义R@1，再对三个差值求均值。记录差值以“百分点”表示，不要把负差值隐去。

说明多正例方法额外用了什么监督。比较训练损失时，为什么不能直接用最小绝对loss宣布获胜？解释附加温度实验为什么只能称为单种子诊断。

## 7 一项可证伪的扩展

从以下方向选一个，先写500字协议，再实施：

- 组合留出：留出若干颜色×形状×位置组合，训练中仍覆盖各个单独属性
- 模板留出：训练只用一种固定模板，测试用另一种；明确这并不是真实自然语言泛化
- 干扰变化：扩大图像噪声或改变亮度，按相同基础实例做配对变换
- 候选池变化：增加每类实例数，分别观察配对与语义指标如何变化

协议必须包含主问题、训练/验证/测试边界、全部方法、全部种子、主指标、停止条件、总训练预算与失败时如何解释。结果不好也应交付；不要把探索阶段看过的测试集继续称为未触碰测试。
