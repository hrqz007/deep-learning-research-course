# 合成教学数据

batch.csv只有8条人工二维输入，ID为s0–s7。取{-1,0,1}二维网格中除(0,0)外的8点，按文件顺序排列。target=0.7*x1-0.4*x2+0.2，全部数为无单位教学量。

random_target用Python标准库独立发生器random.Random(31)依次生成8个uniform(-1,1)并round到3位小数。它是固定随机回归标签，不是分类类别；训练每步复用同一列，不重新抽样。随机标签不从输入规则计算，不用于泛化评价。

config.json给出13参数平滑网络初始theta（W1逐行6个、b1的3个、W2的3个、b2的1个）、6个差分步长，以及49参数网络的种子、1600次Adam更新、学习率0.03。两种规模承担不同诊断：前4条用于完整trace与13坐标差分，全部8条用于单批次拟合。300步矛盾重复标签例由程序内部明确构造，不从文件读取。

figure-input-sha256.json涵盖2个固定输入与全部7个固定输出；图和Notebook第一格先校验。固定CLI不是通用JSON配置器；修改数据需用公开助手函数形成新实验，不能复用教材结论。

没有个人数据、外部抓取数据或训练外验证/测试样本。
