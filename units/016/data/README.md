# 原创有限总体计数

inspection_counts.csv有四行，defective与flagged均为整数0或1，count为非负整数。四种组合必须各出现一次，总数必须正。当前四格882、98、2、18合计1000件。每个编号等权，四种属性组合不是等权样本点。

这是一套完整的合成总体设定，不是从真实设备抽样获得的估计。Bayes扫描另假设两种条件标记率固定，不能据此推断真实分布迁移。因果世界和5件抽样例子在代码中完全枚举，无随机模拟。

输出JSON保存精确分数字符串及展示小数；prevalence_scan.csv为五组先验扫描。测试用固定seed生成另100个小总体，再逐个编号精确枚举，seed只用于可重现测试夹具，不参与教材主例。
