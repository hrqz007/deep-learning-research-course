# 完全合成的比较实验

seed_scores.csv 的八行是人为设定的两种方法错误率百分数，用于配对计算。没有训练真实模型，不代表真实任务成绩。seed_id 0..7 是配对编号；error_A/error_B 是0..100的整数百分数，差异单位为百分点。

plan.json 固定主比较、方向、全部八个配对、区间方法、重采样单位和3个百分点实际门槛。它是教学协议，不是外部预注册或时间戳证明。config.json 控制bootstrap次数、选择模拟次数与伪随机种子；实验只在声明预算内运行。

其他机制直接写在脚本中：稀有差异20×Bernoulli(0.01)，四实体复制例，纯噪声选择与2×2消融。全部无个人资料、外部下载或付费调用。
