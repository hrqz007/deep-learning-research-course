# 原创合成数据

所有数据由本单元作者为纸笔核算设计，不是人群、机构或模型测量。

- distributions.csv：name为分布名，A/B/C为同一有序三状态空间上的概率质量。每行应非负并归一化。1/3以双精度兼容有限小数存储；程序明确允许不超过1e-12的舍入总和误差并归一化，其他错误拒绝。
- labels.csv：四个固定观察[A,A,B,C]，position从1连续编号，label的0/1/2分别对应A/B/C。这是特意设定的经验频率，与未知真实总体无关。position不作预测特征。
- main_p/main_q用于bit手算；zero_p/zero_q用于零支持；target/broad/left/right用于只有三个候选的受限比较。

状态标签及其顺序属于数据定义。更换顺序必须同时重排两个分布；只重排一个会改变问题。数据无随机seed，不需下载或API。
