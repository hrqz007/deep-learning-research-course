## 二 读懂合成数据

分布文件data/distributions.csv每行一个分布，列A、B、C是固定状态顺序。name是标识，不是概率。main_p与main_q是主例；zero_p与zero_q检查零支持；target、broad、left、right用于受限三候选比较。表里的1/3写成有限小数，程序只允许10⁻¹²以内的舍入总和误差并进行明确归一化。

data/labels.csv列出四个固定标签，0、1、2分别对应A、B、C。这四条观测被特意设计为[A,A,B,C]，并非从真实总体采集或随机模拟出的普遍规律。position仅保持顺序，不能当成模型特征。

开始前检查每行概率是否非负、和是否为1；两个分布是否对应同一套有序标签；有哪些状态概率为0。脚本只知道数组的顺序，无法自动发现“两个CSV用同样的列名却暗中交换类别含义”的语义错误。

## 三 先用bit完成主例手算

在纸上写出P=(1/2,1/4,1/4)、Q=(1/4,1/4,1/2)。分别列出−log₂p、−log₂q、p log₂(p/q)，然后用P的概率加权。预期结果为H₂(P)=1.5、H₂(P,Q)=1.75、D₂(P∥Q)=0.25。KL分项应为0.5、0、−0.25，不能把负项删除。

```python
from experiment import entropy, cross_entropy, kl, kl_terms
p = [.5, .25, .25]
q = [.25, .25, .5]
print(entropy(p, 2), cross_entropy(p, q, 2), kl(p, q, 2))
print(kl_terms(p, q, 2))
```

将bit结果各乘ln2，比较nat值1.0397207708、1.2130075660、0.1732867951。再计算交叉熵−熵−KL，正常差值应只有浮点舍入规模。不要仅检验这个恒等式就宣布函数正确，因为三个函数若共享同一个错误，仍可能彼此吻合。

独立核对方法是直接使用有理数权重与80位Decimal的ln。test_experiment.py对分母6的全部28个三状态分布逐对比较，共784对。它保留支持集引起的无穷结果，不会把无穷统一裁为一个大常数。

## 四 在求对数前观察零概率

先预测下面三个结果，再运行：

```python
import math
p0 = [.5, .5, 0]
q0 = [1, 0, 0]
print(cross_entropy(p0, q0))
print(kl(p0, q0), kl(q0, p0))
print(kl([1, 0], [1, 0]))
```

交叉熵和正向KL应为inf，反向应为ln2，共同零状态的KL为0。解释“inf”时写出是哪一个正质量状态遇到零分母；不要只写“除零错误”。这里inf是数学上正确的扩展值，程序不应将其误标为非法输入。

作为对照，尝试交叉熵cross_entropy([0,1],[1,1e-300])。它仍有限，约690.775528；第二个向量总和在浮点内舍入为1，函数接受这一舍入级近似。极小正数和精确零是两种情况。对于尚未转为float的极小正有理数，如果转换会下溢到0，验证器会拒绝，避免误造支持集变化。

summary.json为标准JSON，把无穷记录为字符串“Infinity”。这与数学计算返回的float正无穷在序列化形式上不同；后续分析必须显式识别，不能当作普通数字相加。

## 五 改变小概率而不改变目标

打开epsilon.csv。它固定P=(1/2,1/2)，依次令Q=(1−ε,ε)，ε从10⁻¹递减到10⁻¹²。每行同时计算交叉熵、正向KL和反向KL。应观察到正向持续增大，反向逐渐接近ln2。

自己从定义推出H(P,Q)=−(1/2)ln[ε(1−ε)]，并检查D(P∥Q)=H(P,Q)−ln2。用公式预测再将ε缩小100倍时，正向KL在很小ε下大约增加ln10≈2.302585；这只是渐近近似，有限ε还带有ln(1−ε)修正。

图6展示这些计算值。曲线并没有画出ε=0的有限高度；无穷是端点性质，不能从图上某个最大值代替。最后写清楚为何反方向的权重也随ε变化。

## 七 从四条标签检查经验损失

data/labels.csv的标签顺序是0、0、1、2。模型Q对四条观察都使用同一个概率向量。计算四个负对数损失并平均，再统计标签频率并求经验交叉熵，二者都应为1.2130075660 nat。

```python
from experiment import load_labels, empirical_distribution, mean_nll
labels = load_labels()
p_hat = empirical_distribution(labels, 3)
print(p_hat)
print(mean_nll(labels, q), cross_entropy(p_hat, q))
```

等式来自有限求和重排，不依赖样本独立。但是把它解释成未知总体损失的可靠估计，需要抽样条件、固定评估模型及有限期望等前提。将第一条标签复制100次改变了经验权重，并不自动增加100个独立证据。

接着解释罕见事件反例：P=(0.999,0.001)、Q=(1,0)，100次独立观察完全没有罕见事件的概率约0.904792。这样的批次经验损失为0，总体交叉熵却是无穷。指出这里破坏了前面哪一个支持集条件。

## 八 有意触发输入拒绝

逐一把概率改为负数、让总和变成0.4、插入NaN或True、提供不同长度的P和Q、把标签写成3，确认每种情况得到ValueError。不要删除验证以使程序“继续跑”。示例使用try/except仅为了显示预期拒绝；任何意外成功都应主动报错。

```python
for bad in ([.2, .2], [-.1, 1.1], [True, 0]):
    try:
        entropy(bad)
    except ValueError as exc:
        print(type(exc).__name__, str(exc))
    else:
        raise AssertionError("invalid input was accepted")
```

另作语义失败实验：把Q的A和C列交换但不改变P。函数可能仍能运行，因为归一化、长度都正确；这表明结构校验无法代替类别映射检查。可靠做法是按状态名对齐，再转换为数组，并为已知标签的预测写一个预期值测试。

## 九 平滑是修改模型

调用mix_with_uniform([1,0,0],.02)，应得到(74/75,1/150,1/150)，对P=(1/2,1/2,0)交叉熵为2.5120291572 nat。它有限而原交叉熵无限，因为新的Q给原本缺失的状态留了概率。
