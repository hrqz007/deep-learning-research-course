# 035 激活初始化与信号传播

既定深度学习科研基础课程第035讲。先修018、027、031。主题：在明确随机对象与独立条件下推导前向/反向二阶矩传播，理解Xavier/He的动机与边界，并用逐层测量核对。

## 阅读与运行

- lecture.md / lecture.pdf：完整推导及两样本13参数前向、标量损失、每条局部导数、全部梯度、更新和新前向。
- lab.md / lab.pdf：独立实验指南、数据协议、字段、统计轴及错误输入保护。
- answers.md / answers.pdf：8题详解与科研结论边界。
- experiment.ipynb：已顺序实际执行的Notebook；请清空内核后从头运行。
- experiment.py、test_experiment.py、make_figures.py：可独立运行的实现、测试和绘图。
- data：冻结合成训练数据、手算数据与生成说明。
- outputs：真实执行保存的5个数值文件（其中一个为无损gzip）；figures：11张原创图。
- sources.md：已实际查阅的一手来源与版本。
- verification.json：作者验证范围和限制；不是独立验收结论。

用environment.yml建立环境后，在035目录运行：

```bash
python test_experiment.py
python experiment.py
python make_figures.py
```

脚本默认按自身路径找到data和outputs，因此可从任意工作目录以绝对路径调用。`--output`可指定另一目录；有相对路径参数时，它们按当前工作目录解释。完整扫描通常可在普通CPU上完成，实际耗时受机器影响。实验使用float64、单线程、确定性算法，不下载数据。

Notebook的启动工作目录应为035目录；如果从仓库根启动，首个代码格也会尝试units/035。运行所有代码格会在临时目录重做完整实验，比较5个文件的SHA-256，然后移除临时重跑目录；不会把临时运行写成新的参考答案。若你改变任何协议，摘要比较应失败，这时应先解释改变而不是忽略失败。

分布原始数值存于`outputs/selected_distributions.json.gz`。它保留全部1,179,648个数值，解压后得到原始UTF-8 JSON完整字节（包含空格与末尾换行），没有删样本或降低精度。使用标准库`gzip.open(path, 'rt', encoding='utf-8')`配合`json.load`即可读取；绘图脚本已直接读取压缩文件，不必另存解压副本。

压缩使用level=9、mtime=0、空的内部文件名；因此不写入运行时间或本机路径。固定版本重跑同时比较压缩SHA-256与解压后SHA-256。压缩文件10,083,657字节，解压23,870,931字节；解压内容SHA-256为`14aa21584fc6fd57f1b38b84e11aba100c67c0f22b30c7fd7625460c9ac6cd10`。压缩器版本变化可能改变压缩字节，但不得改变解压内容；改变实验协议另当别论。手动解压的副本不是第六个发布参考文件。

## 结果范围与解释

主扫描4种激活×4种尺度×3种子，共48配置。每配置12层，初始化统计576行。训练最多100次更新；11配置触发预设损失上限停止，37配置完成。停止配置没有第100步成绩，最后有限记录不能与完成者的第100步不加说明地平均。另有宽8/32/128各16种子、共48行的初始化宽度对照。

激活统计默认池化样本与单元位置；方差用元素数作分母。任务梯度和独立终端探针是不同对象，图示与CSV分开标记。训练曲线仅是人工任务拟合，无验证/测试数据，无现实泛化估计。
