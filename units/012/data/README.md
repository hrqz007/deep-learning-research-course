# 原创合成网络配置

network.json无真实样本、个人信息或外部数据，所有数值均无量纲。

- X每行一个样本，Y每行对应一个目标
- parameters只包含W1、b1、W2、b2，偏置显式为一行
- difference_steps依次用于所有参数及输入的中心差分；1e-17故意无法分辨
- loss定义为平方残差之和除2N，不再除输出数C

核心接口支持兼容的非空二维矩阵，任意C时Y都必须与预测严格同shape。随附纸笔与图使用固定2×2×2×1算例，改变配置后不能继续套用正文数值。脚本不会修改本文件。outputs/results.json保存实际前向、梯度、显式雅可比与乘积检查；difference_scan.csv空误差字段表示本次计算被拒绝。
