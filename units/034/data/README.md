# 034 教学数据说明

所有数据均为原创合成教学数据，无个人记录、网页采集或外部许可数据集。

- samples.csv：80行，id为0至79；split固定前48行train、接16行validation、最后16行test。x1与x2来自NumPy default_rng(3400)的[-1,1]均匀分布。生成目标y=.6x1−.4x2+.5max(x1+x2,0)+noise，noise为标准差.12的零均值Gaussian。固定CSV字节是实验权威输入，不要求学习者依靠随机算法跨版本重建相同小数。
- hand-example.json：独立的两行手算示例，数据与九个初值沿用033，新的优化器参数alpha=.02、betas=.8/.9、epsilon=.001、两次更新，不含衰减。
- config.json：固定搜索和预算。主模型与手算同为2→2→1 ReLU。所有训练相同初值；seed340/341/342只改变48行训练数据的epoch重排。每次16epoch×6步=96步，batch8，共768次样本呈现。W和输出权重衰减，两个偏置组不衰减。
- figure-input-sha256.json：三份固定输入及八份原始报告的摘要清单，帮助核对配套图；不是密钥或访问控制。

搜索只接收train和validation。每家族9配置×3顺序，最后一步验证半MSE均值最小者入选，同分取较小网格编号。先冻结3个配置，再计算9个测试值；测试成绩不参与本次选择。提供测试标签是为了可重复练习，不构成未来不可见的盲测服务。若基于本公开测试继续设计方法，后续评价应重新封存独立数据。

未拟合全体数据的尺度，也没有用真实生成函数作为候选选择标准。训练损失、验证损失和测试损失统一为mean((prediction−y)²)/2，不附加L2项，以便跨算法比较同一数据目标。
