# DL093 实验：用可见噪声标签学习不可见边缘score

## 目标、预算与目录

这个CPU实验不下载外部数据、不训练深网络。它用NumPy拟合一个六参数仿射场，目的是验证DSM恒等式并检查低密度区域。默认训练60000点、独立测试30000点，通常几十秒以内完成，磁盘输出约数MB。使用Python 3.10或以上、NumPy和Matplotlib。当前批次已实际执行实验与测试。

在本讲目录运行：

```bash
python experiment.py
python tests.py
```

experiment.py包含全部生成、训练、评价、画图逻辑。outputs/data.npz保存训练与测试数组、标签、权重、解析score及网格结果；outputs/metrics.json保存真正运行指标；figures包含三张图。replay_output.txt记录本批执行输出。不要把手写预期数值误当成程序实测值。

## 2 跟踪数据流

打开sample函数。clean是干净样本；noise是标准高斯；noisy=clean+sigma*noise；target=−noise/sigma。再用代数验证target=(clean−noisy)/sigma²。两种写法都对，但不能混成−noise/sigma²。

fit函数仅接收noisy和target。训练设计矩阵最后一列全为1，允许学习非零均值引起的偏置。若删除此列，模型只能表达经过原点的线性场，本讲非零均值下会产生不可消除的偏差。这是有意义的故障注入，而不是单纯语法错误。

测试种子9302与训练种子9301不同，测试点没有进入拟合。代码中的解析score只用于评价。请在阅读时用不同颜色标记训练信息与评价信息，确认没有把答案偷偷回传给模型。

## 3 检查核心指标

默认真实结果：score_mse_per_coordinate约0.0001395；coefficient_max_absolute_error约0.00454；测试DSM MSE约2.08279；解析oracle的测试DSM MSE约2.08275。不同NumPy线性代数后端可能有末位差异。

每坐标MSE是所有N×2元素的平方差平均，不是每个向量平方范数的平均，二者相差维数2。图2左侧却画向量误差范数，因此不能把色条数字直接当作右侧柱高。

测试验收要求score MSE低于0.005，系数最大绝对误差低于0.05。阈值用于该固定合成设置的教学检查，不是所有生成模型通用质量标准。

## 6 常见故障与定位

如果箭头朝外，先查负号。如果模型输出接近正确方向但幅度严重偏差，查σ与σ²。若训练残差仍很大却score误差小，查看oracle DSM损失，这可能是正常的标签随机性。若仅中心误差小，检查尾部样本数、网格覆盖和斜率误差。

若Matplotlib提示系统字体缓存不可写，代码已把MPLCONFIGDIR放到可写临时目录；英文图标签不依赖中文字体。生成图仍应实际打开核对，不能只凭文件存在判定成功。
