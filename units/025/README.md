## 核心结果与范围

- 2→2→1有9个标量参数；2→3→2→1有20个
- 主构造隐藏激活后为(0,0)、(1,0)、(1,0)、(2,1)，logit为−1、1、1、−1
- ReLU构造四点全对，尺度1平均交叉熵0.313261688
- 去掉隐藏ReLU、保持同权重，logit为3、1、1、−1，正确率0.75，损失0.997093104
- 125个仿射候选中最低交叉熵为log(2)，对应全零参数；该候选正确率0.5，网格最高正确率0.75
- 5个输出尺度候选中8最佳，四点损失0.000335406；这只是有限一维候选搜索
- 两个同样拟合四角点的ReLU网络在中心给出相反logit，提醒连续域内部没有标签证据

实验不执行九参数连续训练，不提前使用反向传播。四点XOR真值表被穷尽核对，但不能据此宣称连续输入或现实任务泛化、训练效率或样本效率。通用逼近只作为带明确条件的存在性命题。

## 输入与输出契约

核心API要求有限实数数组，拒绝布尔、复数、字符串、对象数组、空数组、形状不符和溢出。输入数值绝对值上限为1e100；网络最多10个仿射层、每层宽度最多128、前向样本数最多100000，数组最多2000000项。从扩展浮点转换为float64时，非零值若变成零也会拒绝；若调用者先把文本转成已经为0的Python浮点数，原始信息已经丢失，接口无法反推出它。代码保留所有网络输出二维，偏置必须一维；损失输入logit和标签都是一维。

CSV严格检查唯一表头、行宽、ID和原始四行字节；JSON拒绝重复、额外或缺失键以及非有限值，并在Decimal原始数值阶段与固定配置精确比较，阻止极小非零或近整数被浮点舍入后误认为默认值；真正的0e-400可接受并归一化。固定教学入口只接受默认配置和四角点，不能将自定义实验静默套入旧图与解释。通用核心API用于另行探索。

所有输入、计算和JSON/CSV序列化成功后才改写结果；路径与目标文件拒绝符号链接，避免覆盖输入。此实现不是跨文件崩溃事务，不保证磁盘故障、断电或并发路径交换下的原子性。严格输出字节比较可能在其他平台出现浮点末位差异，应另存并核对，不删除守卫后宣称复现。
