# 主要来源与作用

- [Dropout original paper](https://jmlr.org/papers/v15/srivastava14a.html)：2014论文主张与实验范围。

- [PyTorch Dropout](https://docs.pytorch.org/docs/2.14/generated/torch.nn.Dropout.html)：inverted dropout与eval语义。

- [ML Reproducibility Checklist](https://www.cs.mcgill.ca/~jpineau/ReproducibilityChecklist.pdf)：预算拆分基线运行记录。

- [PyTorch Reproducibility](https://docs.pytorch.org/docs/2.14/notes/randomness.html)：随机性与可复查边界。

接口文档可能更新，实际执行版本以verification.json为准。来源支持概念与接口，结果和图来自本单元独立实验。
