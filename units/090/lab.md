# DL090 实验：判断两个音调的先后

## 目标与交付

你将完成一个离线可重放的时间结构实验，提交分帧计算、时间标签审计、三方法比较、逐源结果与一页研究结论。先读 lecture.md；遇到术语可返回对应章节。本实验不需要真实录音、账号、麦克风、GPU 或商业 API。

环境建议 Python 3.12，依赖 NumPy 2.3.5、matplotlib 3.10.8。Notebook 的制作和执行另需 nbformat、ipykernel、IPython，核心命令行实验不依赖它们。requirements.txt 锁定已经实际验证的核心版本；可在独立虚拟环境中安装。

## 1 从干净目录运行

在本单元目录运行：

```bash
python -m pip install -r requirements.txt
python -m unittest -v test_experiment.py
python -O -m unittest -v test_experiment.py
python experiment.py --output my_run
```

默认输出目录为 outputs；建议自己的实验用 my_run，避免覆盖随课数值。图保存在输出目录旁的 figures，下次画图会覆盖同名 PNG，所以需要保留原图时请先复制整个单元。主实验一般数秒完成，实际时间依机器而异；安装依赖之后，数据生成与训练不联网。

如果图像库提示字体缓存不可写，指定一个你可写的 MPLCONFIGDIR。该问题不影响数学定义；不要因此把未生成图像写成已完成。记录 Python、NumPy、matplotlib 版本以及你实际运行的命令。

## 2 第一轮只核对数据，不看准确率

打开 data.npz，检查 waves、labels、groups、pairs、split、bands。应有 480 段、40 个源；每源 12 段且标签均衡。观察同一 pair 的两段，确认它们真的是交换两个完整短音块，不是重新独立合成。

写下以下 shape，先手算再用代码验证：waves 为 [480,4096]；分帧为 [480,61,256]；复数 STFT 为 [480,61,129]；频带特征为 [480,61,2]；时间模型特征为 [480,8]。若任何数不同，先检查窗口、步长、补零与 FFT 轴，不要立即修改网络。

分区样本量应为 288/96/96，源数量为 24/8/8。用集合交集确认 train、validation、test 源 ID 两两不交。pair ID 也不跨角色。标签均衡来自生成协议，不意味着真实数据天然均衡。

## 3 采样与频谱手算

计算 Δt、窗口覆盖时长、步长时长、频率网格间隔以及第 32 个频率点。然后检查图 02 的混叠例子：1000 Hz 与相位翻转的 7000 Hz 为何具有相同离散样本？记录 alias_max_error，解释它是恒等式的浮点残差而非训练误差。

修改图中的分析窗长为 128 和 512，仅观察频率主瓣与短时事件边界。把此步骤标记为探索，不覆盖原协议的主要结果。不要把零填充 FFT 的点数变多写成时间观测变长。

## 4 时间标签审计

读取 alignment.csv，画出 frame、start_sample、center_s 与 second_event_overlap。手算第 30 与 31 帧。确认事件边界为 0.256 秒，窗口从左闭右开的区间与事件求交。

故障植入 A：把 fs 从 8000 改成 16000，但不改变波形数组；记录片段时长与频率坐标如何变化。此时是在改变信号解释，不是正确重采样。

故障植入 B：假设先删除波形开头 800 个样本，却仍沿用原事件秒数。计算错位量，并给出正确的裁剪标签变换。不要用“模型能学习对齐”掩盖数据管线错误。

这两个故障必须在副本中运行，完成后恢复默认文件。报告应保留你观察到的错误及其定位过程，不要只放修复后的图。

## 5 三方法公平比较

读取 results.csv，逐行检查 temporal、pooled、shuffle_train 的三种子结果。记录训练特征、测试特征、参数量和共同训练预算。所有分类器使用同样损失形式与 600 次更新，但特征维度不同；这是表示对照，不是参数量完全匹配的架构实验。

对每个模型分别报告有序测试与帧置乱诊断。特别检查 pooled 的置乱前后预测差是否接近浮点精度。将所有帧先置乱再平均，应保持相同特征；这是比“差不多准确率”更强的实现不变性检查。

不要删掉 shuffle_train 在有序域出现 0%、0%、100% 的结果。写下它与置乱域结果不同的原因，并提出下一轮检验：例如每次更新重新置乱、增加独立源、比较各系数与有序测试 logit 的范围。下一轮的设置必须单独报告，不替换当前结果。

## 6 独立重放与参数检查

运行 verify_replay.py。它读取保存权重、标准化统计量和数据，重新计算逐例概率与指标，不依靠原来打印的表格。预测一致说明保存文件足以重建指定推理过程；不说明模型对任何未来数据可靠。

任选一组权重，打印前四段两频带的系数。结合标签 1 为高后低，解释系数方向。标准化后系数不能直接等同原始频带能量的物理影响，需考虑标准差。对于 shuffle_train，检查训练特征尺度与有序特征尺度的差异。

## 7 研究结论与替代解释

你的报告应回答：有序时间特征是否优于池化？测试置乱影响是否符合模型不变性？按段随机切分会共享多少生成源？哪些结果仅为合成机制证据？三个种子的变化来源是什么？

至少列出三条局限：仅两种频带及固定时长；只有 8 个保留源；人工频带包含强任务先验；帧置乱不是自然音频分布；配对样本不独立；没有语音或真实视频检验。选择与你的主张真正相关的局限，不要只附一串通用套话。
