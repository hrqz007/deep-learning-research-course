# 合成数据说明

数据由experiment.py的make_data()离线生成，实际数组随outputs/data.npz交付。固定数据种子5800；训练640、验证160、测试320，每个划分两类平衡。八维原始因素的标准差依次为3、2、标签信号0.5*y+0.08*epsilon、以及五个0.1噪声因素，再用同一个8×8正交矩阵旋转。所有输入保存为float32，标签为-1和1，旋转矩阵保存为float64。

不存在外部下载地址；run()会重新生成并保存完全相同的数据。训练输入均值用于AE与PCA中心化，没有逐坐标标准化。分类探测另外只用训练前128例表示拟合标准化统计。许可见../DATA_LICENSE.md。
