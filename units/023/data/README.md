# 原创固定合成数据

samples.csv包含30条确定性合成样本，无真实个人、机构或外部数据。合成目标为：

y = 1.5 + 2*x1 - 0.75*x2 + 0.2*x2*(x1 - 0.5)

特征和目标单位均为本讲规定的合成数值单位。最后的交互项没有放入训练模型；它不是独立随机噪声。生成时以x1为外循环、x2为内循环，目标按12位有效数字写入CSV；本表小数在该精度足够精确。源代码运行时不再随机生成或重新拆分。

## 字段与固定拆分

CSV必须具有精确、唯一且有序的五个表头：sample_id,split,x1,x2,y。每一行也必须恰好五列。

- sample_id：非空唯一字符串；不可跨拆分重复，无前后空白
- split：严格为train、validation或test，三者均非空
- x1、x2：两个有限实数特征
- y：有限实数目标；所有数值绝对值不超过1e100，拒绝空值/前后空白
- train：x1为−2、−1、0、1、2、3，x2为−1、1，12种组合
- validation：x1为−1.75、−0.25、1.25、2.75，x2为−0.5、0.5，8种组合
- test：x1为−1.5、−0.5、0.5、1.5、2.5，x2为−1、1，10种组合

拆分是预先指定的不同网格，既不是随机IID样本，也不是时间/实体切分案例。不从这里声称未来总体误差、置信区间或真实泛化表现。所有文件可读；“测试”是使用约定，不是权限封存。

## 配置

config.json含精确的五个键：learning_rate、steps、initial、gradient_point、fd_step。初值和检查点顺序为w1、w2、b。默认0.1学习率、300次更新、全零初值；差分点[0.4,-0.2,0.7]，差分步长1e-5。

JSON重复键、额外键、布尔参数、错误形状、非有限数据和过大计算预算都会被拒绝。一般核心函数支持1至64个特征、1至10000条样本；CLI的本数据协议固定两个特征，全部行最多10000，更新步数为0至10000的整数，并限制(steps+1)*X.size不超过10000000。

默认固定图与Notebook核对配置、samples.csv字节摘要和重算后的四份结果。跨平台数值库或CSV换行转换也可能引起严格拒绝；这不是数学失败。自定义实验通过脚本另存，并自行核验新的解释，不静默沿用固定图题。原始数据摘要以experiment.py中的TEACHING_DATA_SHA256为准。
