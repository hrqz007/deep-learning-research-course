# 原创合成数据

hand-example.json：3行二维输入、3标签、13初始参数、epsilon1/3、SGD学习率.1。参数顺序在experiment.py的ORDER中明确，W按行展开。两列隐藏特征及输入行有特殊线性关系，为便于精确手算，不能据此推断现实可识别性。

config.json：固定锚点与随机同伴采样种子3600，batch大小2/4/8/32，各200次，epsilon.001；训练重排种子360/361/362。种子控制局部NumPy生成器。

samples.json：用default_rng(3636)生成96行二维标准正态输入。标签为.7x1−.4x2+.3tanh(x1+x2)+独立标准差.08高斯噪声。按生成顺序前64训练、后32诊断验证；没有独立测试集或调参选优。数值随文件冻结，不依赖运行时再生成。

figure-input-sha256.json：图生成程序检查3份固定输入和9份输出的摘要。它不是新的观测数据，也不是算法优劣证据。

实验结果不含任何私人数据。所有报告使用相对路径。32个验证样本仅用于展示正确/错误评价状态，无总体泛化或部署质量声明。
