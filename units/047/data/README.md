# 047 原创图像数据

images.json包含128训练池、64验证、256测试图，种子4701/4702/4703。每图NCHW为1×8×8。标签0为长度3宽1竖条，1为横条，类别各半；中心行列独立取2至5，像素独立Gaussian噪声std0.16，条形位置加1。数据为原创数值模拟，不含真实人物或外部图片。

32图训练集为128池的前32图，二者嵌套，不是独立抽样。验证只做描述性最终读数，未进行超参选择。测试标签公开适合教学，不是保密盲测。

protocol固定三模型、三初始化种子、200步full-batch SGD、lr0.15，无预训练/增强/尺度拟合。跨规模图呈现量同时改变4倍，不声称纯样本效率曲线。data_manifest.json覆盖数据原字节。

事后添加的邻接相关方向规则不改变数据与原神经协议，明确记录在results.orientation_reference，其零阈值分数不是概率logit。不要把它写成预先冻结的神经处理。

生成器可用python generate_data.py --output generated-data重建；指定目录同名文件会覆盖，建议保留原件。参考NumPy2.3.5，跨版本字节一致未保证。
