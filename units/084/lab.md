# DL084 实验：从手算梯度到随机轨迹

## 研究问题

本实验分三层：单步bandit的解析梯度；四条轨迹的MDP精确梯度；Monte Carlo及基线、离策略校正。训练曲线采用精确梯度上升，不能称为随机REINFORCE学习曲线。交付每层的数值、误差和适用条件。

## 1 环境与运行

核心只需Python和NumPy。完整Notebook、图与PDF环境见requirements.txt。

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python experiment.py
python -m unittest -v test_experiment
python -O -m unittest -v test_experiment
```

运行后检查metrics.json、trajectories.json、gradient_samples.npz和history.json。没有网络、GPU或环境服务。全程采样规模约十万量级，普通CPU可运行。

## 2 手算bandit后再运行

θ=0时p=0.5。写出平均奖励(0.2+0.8)/2=0.5，梯度0.25×0.6=0.15。调用bandit_exact(0)核对。再取θ=0.3，解释为什么p变大、收益增大，而梯度不一定也增大：sigmoid在极端区域变平。

调用bandit_samples(0.3,100000)。每个返回元素是(a−p)r，而不是奖励本身。求均值与方差，和解析梯度比较。不要只取一次动作就判断估计对错。将种子改为另一个值，观察误差方向可以变化。

## 3 枚举两步MDP

固定参数[0.2,−0.4,0.7]、γ=0.9。列四行表：动作对、轨迹概率、r₀、r₁、G₀和score。四个概率之和应为1，回报应为0.09、0.36、−0.1、0.8。score的第二或第三坐标中有一个为0，因为该分支未访问。

把每行概率×回报相加，得到J约0.364962。再把概率×回报×score逐坐标相加，得到[0.075001,0.029202,0.109715]。这些是精确枚举值，浮点舍入之外没有Monte Carlo误差。

## 4 检查梯度而不依赖学习曲线

读test_mdp_gradient：对每个θ坐标加减10⁻⁵，计算收益中心差分，与解析score估计比较。测试通过后再看优化曲线。曲线上升不能排除梯度实现错误，因为错误方向也可能偶然提高收益。

把γ设为0，目标应只剩第一步代价，J=−0.1sigmoid(θ₀)，第二状态的动作不再影响目标。这个边界测试检验折扣语义，比仅在γ=0.9跑通更有诊断价值。

## 5 随机估计与标准误

调用mdp_mc产生50000条独立轨迹的梯度向量。计算均值、标准差和标准误s/√n。本次均值约[0.073402,0.029468,0.108967]。把它们和解析梯度一起画，误差条必须标明是标准误、标准差还是置信区间。

减小n为500、5000，再增至50000，保持种子后比较误差尺度。误差不会对单一随机样本严格单调下降，理论说的是典型或平均行为。不要因为某次小样本恰好更准就否定1/√n趋势。

## 6 基线的配对比较

使用同一参数、同一种子和相同n，分别令baseline=0和baseline=J。此时底层动作轨迹相同，差异只来自减去常数。检查均值仍接近解析梯度，再比较方差。本例三个坐标方差均下降。

额外试baseline=100，预测它会不会更好，然后运行。解释为什么“无偏”不等于“低方差”。如果把基线改成动作相关数值，先精确枚举检查期望是否改变，不可继续套用无偏证明。

## 7 离策略反例

importance_bandit使用目标θ=0.3、行为θ=−1.3。先看uncorrected：约−0.0183，与真实正梯度方向相反。再看importance_corrected：约0.1458，接近0.1467。记录最大权重与ESS，说明校正后的方差仍可能很大。

把行为策略进一步推向极端，只作为数值压力测试。支持覆盖虽未完全为零，罕见动作仍可能几乎采不到，权重异常大。不要在零概率处直接除法；应报告无法从该数据识别目标期望。

## 8 训练与科研表达

history.json是100次精确梯度上升，最终回报约0.7699，最优确定轨迹回报为0.8。写清这一部分不是有噪声的训练。若要扩展为随机训练，请在每步重新采样、用相同环境交互预算比较多个种子，并报告失败运行。

## 验收与故障排查

13项测试在普通与优化模式均通过；概率总和、score均值为0、中心差分、基线期望、折扣边界均核验。若梯度符号错误，先核对是在最大化收益还是最小化负收益；若随机误差异常，核对行为策略、种子和样本单位；若学习停滞，检查sigmoid是否饱和。

最后提交一页结论：什么是精确结果，什么是抽样估计，什么是尚未验证的真实RL扩展。不得将高玩具环境回报描述为LLM安全或科研能力改善。
