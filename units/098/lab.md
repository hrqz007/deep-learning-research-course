# 098｜实验手册

## 1. 任务与预注册协议

你的任务是审计小模型规模外推，而不是追求一条漂亮直线。固定训练数据1024条、验证512条、测试1024条；宽度4/8/16/32参与拟合，宽度64留出；5个种子；Adam学习率0.01；500次全批量更新；CPU单线程。不要看见结果以后修改协议并覆盖原输出。

先预测：扩大宽度可能降低拟合误差，但不保证同样步数内测试误差单调下降；对数曲线可能弯曲；更小误差的模型不一定有最短墙钟时间。将你的预测和理由记录在单独笔记中。

## 2. 安装与运行

在本讲目录执行：

```bash
python -m venv .venv
# 激活该虚拟环境后
python -m pip install -r requirements.txt
python experiment.py
python tests.py
```

Notebook须从本讲目录打开，按顺序运行全部单元。它会重跑实验并读取保存数据；没有外部模型、付费服务或网络数据下载。依赖安装后可离线执行。单线程不代表耗时恒定：CPU型号、系统负载和库版本仍会影响时间。

## 3. 先核对数据与资源记账

打开outputs/data.npz，确认三个划分的样本数与维度，验证不同划分不相同。根据第一层和第二层的权重形状手算参数量；对照runs.csv中的25、49、97、193、385。计算512000次样本呈现为什么不等于512000条独立记录。

outputs/training_history.csv每50步及最后一步保存训练损失，但损失对应该步更新前的值；runs.csv的最终训练误差对应全部更新之后。两者最后值不必完全相同。不要将正常的记录时点差异误报为复现失败。

## 4. 从CSV独立恢复拟合

按宽度聚合5个种子的test_mse。取前四个参数量与平均误差的自然对数，用最小二乘求截距与斜率；和metrics.json比较到浮点容差。计算385参数处的预测值和相对误差。解释相对误差的符号，不仅报告绝对数值。

画出四个拟合残差。问：残差是否显示弯曲？最大的种子间差异来自哪个宽度？这些现象是否足以要求新实验？不要把“没有明显证据反对”写成“证明幂律正确”。

## 5. 不确定性与反例

复现配对种子bootstrap，随机种子909、重复1000次。抽样单位是种子对应的整条曲线。画出来的区间是初始化变动下的拟合预测区间，不包含更换数据集和函数形式的风险。

反例练习：只保留两个规模拟合，确认训练拟合残差接近零，再检查其他规模。解释为什么零残差不能证明外推好。把总MSE直接减0.01，检查所有均值是否仍为正；若非正，应停止对数变换，而非任意加一个小常数隐藏问题。

## 6. 提交物与评分

提交一页报告，包含协议、参数量、每规模五次测量、留出相对误差和至少两个限制；附你独立恢复拟合的代码。基础合格要求：tests.py全部通过、Notebook无错误、25次训练记录齐全、所有误差有限、训练数据和输出可追溯。科学合格要求：不将固定步数当固定计算，不把局部指数当普适定律，不以时间差异代替未测量的GPU性能。

扩展只作为新实验：增加数据规模或更新步数；保留旧结果，使用新目录和协议说明。若要找计算最优配置，必须把模型规模和数据量联合扫描，并记录每个配置的完整调参成本。
