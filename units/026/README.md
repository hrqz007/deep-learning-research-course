## 实现与关键数值

Scalar用不可变的数值和有序输入边保存前向历史。拓扑访问按节点身份去重，局部贡献按输入位置保留；backward每次返回新梯度字典，既不跨调用累积，也不自动更新参数。仅支持标量加、乘、负号、tanh、ReLU；广播、高阶求导及一般幂运算不在本实现范围。

主例s=(wx+b)^2+w、L=(s−y)^2/2，x=2、y=1/4、w=1/2、b=−1/4。初始L=169/512，dL/dw=13/4，dL/db=39/32。w的两条路径贡献分别39/16与13/16。13个实现节点、15条输入边。

η=0.02的一次同步更新给w=0.435、b=−0.274375，损失约0.14567536；预定40步后损失约0.000127539。这只拟合一条合成记录，参数解不唯一，不是泛化或现实任务性能证据。

ReLU零点本实现约定局部值0，对称差分却为1/2；该点普通导数不存在。tanh在20处直接1−tanh²会舍入为0，等价稳定式保留约1.69934e−17；自动微分仍有浮点数值限制。

## 输入、输出与失败边界

Scalar节点及数值校验/乘法接口仅接受Python内置int/float，排除bool和非有限值；值、局部导数及中间梯度绝对值最多1e100。非零乘积下溢成0会拒绝，其他舍入与小量被大数吸收不保证检测。tanh输入绝对值最多100。默认运算建图无环；迭代拓扑检查还限制可达节点不超过100000。

JSON拒绝重复/额外/缺失键、错类型、非有限值和文本非零转浮点0。x/y/w/b绝对值最多10，iterations整数0至500，learning_rate从1e-6至0.1。合法配置不保证收敛。输入和计算失败在写出任何文件前停止，保留旧输出；操作系统多文件写故障不具原子保证，也不防御恶意并发路径替换。

自定义配置使用--config custom.json --output custom_outputs。固定Notebook/绘图入口先检查默认配置与五输出摘要，拒绝被改变的默认教材产物。严格摘要可能拒绝跨平台末位差异。PDF复建见[共享构建说明](../../shared/build-tools/README.md)，所有复建页面仍需目视审查。
