## 2 先把Jacobian手算清楚

两个训练点的梯度行分别为(1,0)和(1,2)。问题A：参数增量d=(0.1,-0.2)引起怎样的输出变化？问题B：Gram矩阵是什么？问题C：对v=(1,-1)，计算vᵀKv并与||Jᵀv||²比较。

令m=1，a=2、w=0、b=0、x=3。tanh(0)=0，求f和对a、w、b的三个偏导。注意f虽然为0，改变w或b仍能立刻改变输出；“当前激活为0”不代表所有梯度都为0。

## 3 逐行追踪一次真实与线性化更新

```python
import numpy as np  # 数值数组，全部使用float64。
from generate_data import generate  # 原创固定函数数据。
from experiment import initialize, forward_jacobian  # 手写网络与偏导。
d = generate()  # x为24个训练输入，y为未缩放目标。
theta0 = initialize(8, 11)  # 共24个参数，8个a、8个w、8个b。
f0, j0, h0 = forward_jacobian(theta0, d['x'])  # 得到初始函数、Jacobian、隐层。
k0 = j0 @ j0.T  # 24×24的样本Gram矩阵。
eta = .3 / np.linalg.eigvalsh(k0 / len(d['y']))[-1]  # 固定核谱尺度。
delta = -eta * (j0.T @ (f0-d['y'])) / len(d['y'])  # 两条路径首步相同参数增量。
f_linear = f0 + j0 @ delta  # 线性化在首步的精确输出。
f_real, _, _ = forward_jacobian(theta0+delta, d['x'])  # 真网络首步输出含高阶项。
print(np.sqrt(np.mean((f_real-f_linear)**2)))  # 一般不是严格0。
```

首步参数改变量相同，却不保证输出相同，因为真实函数是弯的。之后真实网络重算Jacobian，线性化网络冻结j0，两条参数路径也会不同。这里不能把线性化参数增量每次强制设成真实theta减theta0，否则你比较的是“沿真实路径的一阶拟合误差”，不是本课的两条独立训练动力学。

## 4 从保存权重重算结果

```python
import numpy as np  # 只加载数值数组。
from experiment import forward_jacobian  # 与训练时同一前向公式。
a = np.load('my_run/trajectories.npz', allow_pickle=False)  # 禁止对象pickle。
key = 'w8_a4_s11'  # 预定配置：宽度8、目标幅度4、种子11。
pred, _, _ = forward_jacobian(a[key+'_theta'], a['grid'])  # 最终真实网络重算。
print(np.max(np.abs(pred-a[key+'_nonlinear_grid'])))  # 同环境通常为0或舍入级。
f0, j0, _ = forward_jacobian(a[key+'_theta0'], a['grid'])  # 网格初始化。
lin = f0 + j0 @ a[key+'_linear_delta']  # 从参数重建线性化输出。
print(np.sqrt(np.mean((pred-lin)**2)) / 4)  # 与JSON相对预测差核对。
```

对27组都做此检查，而不只挑一个成功样例。报告形状、最大绝对差与容差。输出路径中幅度0.2的键含小数点，是普通字符串，不是目录层级。

## 5 做一个能分辨机制的改动
