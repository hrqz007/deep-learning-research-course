# 第001单元原样合成校准数据

数据为课程原创合成，无个人信息或真实测量。train.csv五条训练记录，test_inputs.csv四条测试输入，test_labels.csv对应公开标签，stress_labels.csv对应改变关系后的压力标签。数据字节应与001这四个CSV相同。

x的单位为旋钮格，y的单位为屏幕读数单位，均不对应实际设备。训练标签为3、5、8、9、11；除第三条外采用2x+1。测试关系为2x+1，压力关系为3x+1。

本单元核心脚本使用明确的数值列表，避免引入文件读取作为隐藏先修。verify_experiment.py逐项核对列表与CSV。CSV不是运行必需的外部下载，但作为可审计原始记录必须保留。公开仓库分离标签文件只能演示流程，不构成盲测或访问控制。
