# 原创反序列数据与固定协议

四个普通ID4..7对应A/B/C/D，控制ID0/1/2/3分别为PAD/BOS/EOS/UNK。原始内容不含控制ID；batch在每篇外添加边界。长度2/3/4的336种序列固定打乱，取96训练、32验证、64测试；长度5/6再固定取64外推测试。精确序列在各划分间不重叠，符号片段可共享。

所有数据由generate_data.py生成，无外部或个人文本。sequences.json的protocol在训练前固定seed、维度、步数、学习率、clip、mask和停止规则；manifest.json校验原文件SHA。验证只描述，不选checkpoint；测试不用于改协议。

任务是教学用有限符号转换，不能据此宣称自然语言理解、普遍门控优势或无限记忆。
