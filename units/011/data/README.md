# 原创合成配置

experiment_config.json的所有数值均人为设计，无真实数据、个人信息、抽样或训练过程。全部参数和损失均无量纲。

- provenance：固定来源说明
- point：一条参数行，shape为(1,2)，第1列x、第2列y，固定为[[2,3]]，run会拒绝其他点；若探索其他点，请直接调用通用核心函数
- difference_steps：12个正步长，分别检查坐标与联合路径中心差分；1e-16故意展示输入无法分辨
- linear_scales：三种ε，每次增量为(ε,2ε)，从同一个起点出发
- learning_rates：四个η，每次从同一旧点取梯度并更新，不递推

脚本不修改配置。输出results.json保存前向值、梯度、路径贡献、局部预测、有限更新和不可微反例；difference_scan.csv按配置顺序保存步长、坐标差分、最大绝对误差、路径差分、路径绝对误差和状态。无法计算的数值字段留空，不表示0。environment.json记录当前执行版本。
