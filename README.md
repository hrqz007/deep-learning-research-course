# 面向研究的深度学习课程

从零起点逐步建立深度学习的推导、实现、实验与研究判断能力。

> **制作中。** 本课程规划 72 个主体单元与 6 条高级分支共 30 个深入单元，共 102 个单元。目前已发布课程大纲，正文、实验指南、代码与 Notebook 正在分批制作和验收。大纲中的单元与实验计划不代表已经完成。

## 课程导航

- [完整课程大纲（PDF，49 页）](catalog/curriculum.pdf)

大纲包含课程定位、先修依赖、学习路线、逐单元问题、推导深度、实验和验收要求。它是一套独立的深度学习课程，不要求预先完成另一套机器学习课程。

## 后续教学包

完成的单元将包含连贯正文、机制图解、逐步数学推导、手算例子、独立实验指南、可运行 Notebook 与脚本、教学数据或合法下载说明、练习及详解，并附实际执行和检查范围。

学习时围绕具体研究问题补齐必要先修；单元数量不是课时承诺，也不是开始一个有边界的复现研究之前必须全部读完的清单。玩具数据和小规模实验只支持相应教学结论，不构成现实性能或新研究贡献的证明。

## 发布与使用

只有完成内容、来源、运行和版面检查的单元才列为完整发布；环境与平台未测试的部分会明确说明。

仓库公开，便于在线学习与交流。目前未附加开源许可证；公开可读不代表授予未明确约定的再许可权。
