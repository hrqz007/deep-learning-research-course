# PDF与Notebook构建说明

学习实验仅需各讲requirements.txt。PDF重建还需要Markdown、WeasyPrint、Matplotlib、Node.js、MathJax和中文字体；这些是制作依赖，不是运行实验所必需。

在仓库根的.build-deps目录通过npm安装mathjax-full@3.2.2，Python安装markdown与weasyprint，并安装Noto Sans/Serif CJK字体。运行python shared/build-tools/098-102/build_098_102.py units/098/lecture.md即可生成对应PDF；该构建脚本沿用已验证的MathJax与彩色重点框机制。数学公式在本地转换为SVG，不在PDF运行时请求网络。

shared/build-tools/098-102/execute_notebook_inprocess.py可在禁止socket的环境中以新Python进程内的IPython内核顺序执行Notebook，并保存输出。它验证单元执行，不声称验证浏览器Jupyter界面或跨平台kernel transport。普通Jupyter用户也可在各讲目录打开Notebook顺序运行。

公开构建日志只记录相对文件名、输出字节与成功状态。环境诊断、临时缓存和审核截图不属于学习发布包。更改正文或代码后应重新运行实验、tests、Notebook与PDF视觉检查，并更新manifest和发布SHA清单。
